How Windows 10 Uses Random MAC Addresses on Wi-Fi

Windows 10 enhances user privacy on public Wi-Fi networks by utilizing random hardware addresses, commonly referred to as MAC address randomization. When enabled, this feature prevents network administrators, advertisers, and malicious actors from tracking a physical device across different Wi-Fi networks and locations. By masking the device's true, permanently assigned hardware identifier with dynamically generated alternatives, the operating system limits profile building and shields users from targeted surveillance on untrusted connections.

The Privacy Risk of Static MAC Addresses

Every network interface card (NIC) comes with a factory-assigned Media Access Control (MAC) address, a 12-character alphanumeric code unique to that physical chip. When connecting to or scanning for Wi-Fi networks, a computer broadcasts this address over Layer 2 of the OSI model.

On public networks—such as those in airports, hotels, or cafes—passive listeners and commercial tracking systems can log static MAC addresses. Because the address never changes, third parties can:

  • Correlate network activity across multiple public hotspots.
  • Track an individual’s physical movements and habits over time.
  • Target specific hardware vulnerabilities by analyzing the Organizationally Unique Identifier (OUI), which reveals the hardware manufacturer.

The Mechanics of Random Hardware Addresses in Windows 10

Windows 10 mitigates these threats by implementing MAC address randomization at two critical stages of network interaction:

1. Network Discovery and Scanning

Before a device connects to an access point, it regularly broadcasts probe requests to discover available networks. Windows 10 can use randomized MAC addresses during these background scans. This prevents listening sensors within physical range from harvesting the device’s real identity before a connection is even authorized.

2. Network Association and Communication

When establishing an active connection to a public network, Windows 10 replaces the permanent hardware address with a software-generated, randomized address for all standard communication (including DHCP requests and ARP tables). As far as the public router and any network sniffers are concerned, the device appears as an entirely different, arbitrary machine.

Operating Modes: Daily vs. Persistent Randomization

Windows 10 provides two operational modes for random hardware addresses, balancing continuous privacy with connection stability:

  • Static per Network: Windows generates a unique, pseudo-random MAC address for a specific Wi-Fi network and keeps it for future connections to that same SSID. This ensures consistent authentication on public portals (captive portals) that require login sessions, while still hiding the real physical MAC address.
  • Daily Change: For heightened privacy, users can configure Windows 10 to rotate the MAC address every 24 hours. If a user frequents the same public location daily, the network infrastructure treats the device as a new machine every day, disrupting long-term data collection.

Limitations and the Need for Multi-Layered Security

Random hardware addresses secure identity at Layer 2 (Data Link layer). While this effectively stops physical tracking and device fingerprinting, it does not encrypt payload data.

To maintain end-to-end security on public Wi-Fi, random MAC addresses must work alongside upper-layer protections:

  • HTTPS/TLS: Encrypts application-layer data (Layer 7) between the browser and web servers.
  • Virtual Private Networks (VPNs): Tunnels all IP traffic (Layer 3) through an encrypted pathway, ensuring that even if public Wi-Fi operators observe the randomized MAC address, they cannot inspect visited domains or packet contents.

Enabling Random Hardware Addresses in Windows 10

The feature can be activated globally or per network:

  1. Open Settings and navigate to Network & Internet.
  2. Select Wi-Fi from the left-hand menu.
  3. Toggle the Random hardware addresses switch to On for all future connections.
  4. To apply it to a specific saved network, click Manage known networks, select the desired public network, choose Properties, and set Random hardware addresses to On or Change daily.
