Windows 10 Shared Folders Snap-in fsmgmt.msc Explained

The Shared Folders console (fsmgmt.msc) in Microsoft Windows 10 is a dedicated Microsoft Management Console (MMC) snap-in designed to centrally manage, monitor, and configure shared resources across a local machine or remote network computer. This article explains the primary purpose of the tool, breaks down its core management categories—Shares, Sessions, and Open Files—and highlights how system administrators and power users utilize it to troubleshoot network access and maintain security.

Purpose of the Shared Folders Console

The primary objective of fsmgmt.msc is to eliminate the need to navigate through File Explorer to manage individual network shares. Instead of right-clicking separate directories to inspect sharing properties, the snap-in consolidates all file-sharing operations into a single administrative interface. It provides real-time visibility into who is accessing local data over the network and gives administrators granular control over network permissions and resource availability.

Core Components

The snap-in organizes shared folder management into three distinct sections:

1. Shares

The Shares node displays every shared folder on the system, including standard user-created shares and hidden administrative shares (such as C$, ADMIN$, and IPC$). Through this view, administrators can:

  • Create new shares using the Create a Shared Folder Wizard.
  • Modify share permissions (Read, Change, Full Control) independently of NTFS permissions.
  • Adjust user limits to prevent performance bottlenecks.
  • Stop sharing folders instantly to secure sensitive information.

2. Sessions

The Sessions node provides real-time visibility into all users currently connected to the computer via the Server Message Block (SMB) protocol. It displays:

  • The username and computer name of the connected client.
  • The number of files opened by the session.
  • The total connected time and current idle time.
  • Whether the connection is authenticated as a guest.

Administrators can terminate individual sessions or disconnect all active users simultaneously, which is critical before performing system maintenance or reboots.

3. Open Files

The Open Files node tracks individual files and directories currently locked or accessed by remote users. It lists:

  • The exact file path of the opened resource.
  • The user who has the file open.
  • The access mode (Read, Write, or Create).
  • Any lock counts applied to the resource.

This feature is particularly useful for troubleshooting "file in use" or access-denied errors, allowing administrators to forcibly close a specific locked file without terminating the user's entire network session.

How to Access fsmgmt.msc

You can launch the Shared Folders console in Windows 10 using several direct methods:

  • Press Windows Key + R, type fsmgmt.msc, and press Enter.
  • Open the Computer Management console (compmgmt.msc) and expand System Tools > Shared Folders.
  • Run fsmgmt.msc directly inside Command Prompt or Windows PowerShell with administrative privileges.

Key Benefits

  • Centralization: Manage all network shares from a unified dashboard rather than hunting through the local file system.
  • Auditing and Security: Quickly audit hidden administrative shares and verify that share permissions align with organizational access policies.
  • Proactive Troubleshooting: Resolve file lockups and identify idle or unauthorized sessions impacting local workstation performance.
