How Windows 10 Handles NTFS Alternate Data Streams

This article explores how the Microsoft Windows 10 operating system processes, utilizes, and manages NTFS Alternate Data Streams (ADS). It covers the architectural mechanics of data streams within the NTFS file system, legitimate operating system uses such as the "Mark of the Web" security feature, file manipulation behaviors during transfer operations, and methods administrators use to detect and manage these hidden streams using built-in Windows 10 tools.

What Are NTFS Alternate Data Streams?

Alternate Data Streams are a feature of the New Technology File System (NTFS) designed to provide compatibility with the hierarchical file system (HFS) used by legacy Macintosh systems. In NTFS, every file consists of at least one data stream: the default, unnamed stream known as $DATA, which holds the standard file contents visible to the user.

An Alternate Data Stream allows additional, separate streams of data to be associated with the same file or folder using the syntax filename:streamname. These secondary streams exist independently of the primary file contents without altering the primary file size or modifying its visible attributes in graphical tools.

Legitimate Operating System Functions

Windows 10 natively relies on Alternate Data Streams for critical system and security functions. The most prominent example is the "Mark of the Web" (MotW).

When a user downloads an executable, document, or script via Microsoft Edge, other web browsers, or email clients, Windows 10 automatically attaches an ADS named Zone.Identifier to the file. This stream contains metadata identifying the security zone from which the file originated (such as the Internet Zone). Windows 10 security components, including Microsoft Defender SmartScreen and Microsoft Office Protected View, inspect this stream to prompt the user with security warnings or restrict macro execution until the file is manually unblocked.

Graphical and Shell Visibility

By default, the Windows 10 File Explorer abstracts away Alternate Data Streams. When viewing files in File Explorer, the listed file size reflects only the default data stream. If a 1 MB text file contains an alternate data stream containing 500 MB of data, File Explorer will still report the file size as 1 MB, and opening the file in Notepad will only load the base text.

Because of this abstraction, malicious actors can theoretically use ADS to hide payloads, malicious scripts, or exfiltrated data from casual inspection. However, modern security solutions integrated into Windows 10, such as Microsoft Defender Antivirus, actively scan Alternate Data Streams during on-access and on-demand scans.

Managing ADS via Command Prompt and PowerShell

Windows 10 provides native command-line utilities to view, create, and remove alternate streams without requiring third-party tools.

Using the Command Prompt (cmd.exe)

  • Viewing Streams: The standard dir command includes a /R switch that lists alternate data streams associated with files:

    dir /R

  • Creating Streams: You can write data to an alternate stream by redirecting output:

    echo "Hidden Data" > document.txt:secret.txt

  • Reading Streams: Built-in commands like more can read stream contents:

    more < document.txt:secret.txt

Using PowerShell

Windows 10 includes native PowerShell cmdlets featuring a dedicated -Stream parameter to simplify management:

  • Inspect Streams: Get-Item -Path "file.txt" -Stream * returns all streams associated with a file.
  • View Stream Content: Get-Content -Path "file.txt" -Stream "Zone.Identifier" reads the stream contents directly.
  • Remove Streams: Remove-Item -Path "file.txt" -Stream "Zone.Identifier" deletes a specific alternate stream.
  • Unblock Files: The dedicated Unblock-File -Path "downloaded_file.exe" cmdlet automatically deletes the Zone.Identifier stream, removing the security restrictions imposed on downloaded media.

Behavior During File Operations

The persistence of Alternate Data Streams in Windows 10 depends on the destination storage medium:

  • NTFS to NTFS: When moving or copying a file within an NTFS volume or across different NTFS volumes, Windows preserves all associated alternate data streams.
  • NTFS to Non-NTFS (FAT32, exFAT): File systems like FAT32 and exFAT do not support ADS. If a user attempts to copy an ADS-attached file to a non-NTFS USB drive or network share, Windows 10 will either drop the alternate data streams silently or issue a prompt warning that file properties will be lost.
  • Network Protocols: SMB (Server Message Block) fully supports NTFS streams, allowing them to traverse supported network shares. Conversely, protocols like FTP and HTTP do not natively support ADS and strip them during transmission unless the files are compressed inside an archive format.
