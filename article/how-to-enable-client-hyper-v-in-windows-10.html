How to Enable Client Hyper-V in Windows 10

Client Hyper-V is an optional, native hardware virtualization technology integrated into 64-bit editions of Windows 10 that allows developers, IT professionals, and system testers to create and manage virtual machines directly on their host computers. This article explains how Windows 10 utilizes Client Hyper-V, the foundational hardware and system requirements needed to run it, and the exact steps to enable the hypervisor using native Windows configuration tools.

Architecture of Client Hyper-V

Client Hyper-V operates as a native Type-1 bare-metal hypervisor. When enabled, the Windows hypervisor layer sits directly between the physical hardware and the operating system. The host Windows 10 OS becomes the parent partition (root partition), which manages device drivers and virtualization requests, while guest operating systems run in isolated environments known as child partitions. Because the hypervisor runs directly on the hardware rather than on top of the host operating system, it provides superior performance, stability, and direct access to CPU execution optimizations compared to Type-2 hypervisors.

Prerequisites and Hardware Requirements

Before enabling Hyper-V, the system must meet specific hardware and operating system requirements:

  • Operating System Edition: Windows 10 Pro, Enterprise, or Education (64-bit). Windows 10 Home does not include Client Hyper-V.
  • Processor: 64-bit processor with Second Level Address Translation (SLAT).
  • Virtualization Support: CPU virtualization extensions (Intel VT-x or AMD-V) and Hardware-Enforced Data Execution Prevention (DEP) must be enabled in the system BIOS/UEFI.
  • Memory: At least 4 GB of RAM (more is recommended depending on the number of concurrent guest virtual machines).

To verify system compatibility, open Command Prompt or PowerShell and type:

systeminfo.exe

At the bottom of the output, locate the Hyper-V Requirements section. If all four items read "Yes," the system is ready to host Hyper-V.

Methods to Enable Client Hyper-V

Windows 10 keeps Client Hyper-V turned off by default. It can be enabled using any of the following administrative methods.

1. Enable via Windows Features Dialog

  1. Press Windows Key + R, type optionalfeatures.exe, and press Enter.
  2. Scroll down and locate Hyper-V.
  3. Check the box next to Hyper-V, ensuring both Hyper-V Management Tools and Hyper-V Platform are selected.
  4. Click OK.
  5. Restart the computer when prompted to allow the Windows bootloader to initialize the hypervisor.

2. Enable via PowerShell

  1. Right-click the Start button and select Windows PowerShell (Admin).
  2. Run the following command:
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All
  1. Press Y when prompted to restart the system to complete the installation.

3. Enable via Deployment Image Servicing and Management (DISM)

  1. Open Command Prompt as an administrator.
  2. Execute the following command:
DISM /Online /Enable-Feature /All /FeatureName:Microsoft-Hyper-V
  1. Restart the system once the operation completes successfully.

Launching and Using Client Hyper-V

After the computer restarts, search for Hyper-V Manager in the Windows Start menu. Through the Hyper-V Manager interface, you can configure the Virtual Switch Manager to link internal virtual adapters to your physical network interface, allocate physical processor cores and RAM, and attach installation ISO images to build and deploy virtualized guest operating systems.
