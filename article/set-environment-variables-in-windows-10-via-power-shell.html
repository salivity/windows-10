Set Environment Variables in Windows 10 via PowerShell

This article provides a comprehensive guide on configuring custom environment variables in Windows 10 using PowerShell. It covers creating temporary variables that exist only for the duration of an active terminal session, as well as defining persistent variables at the User and Machine (System) scopes using native .NET methods. You will also learn how to verify and remove these variables efficiently.

Temporary Environment Variables (Session-Only)

Temporary environment variables remain active only for the lifetime of your current PowerShell session. Once the console is closed, the variable is discarded.

To create or update a session-level variable, use the env: PowerShell drive:

$env:CUSTOM_KEY = "CustomValue"

To view the value of this variable within the same session:

$env:CUSTOM_KEY

Persistent Environment Variables (User and System)

To make an environment variable persist across system reboots and new shell sessions, PowerShell leverages the .NET [System.Environment] class.

1. User-Level Environment Variables

User-level variables only apply to the currently logged-in user account and do not require administrator privileges to set.

To create or overwrite a persistent User environment variable:

[System.Environment]::SetEnvironmentVariable('CUSTOM_KEY', 'CustomValue', [System.EnvironmentVariableTarget]::User)

2. System-Level Environment Variables

System-level (Machine) variables apply globally to all users and services on the machine. Running this command requires an elevated PowerShell session (Run as Administrator).

To create or overwrite a persistent Machine environment variable:

[System.Environment]::SetEnvironmentVariable('CUSTOM_KEY', 'CustomValue', [System.EnvironmentVariableTarget]::Machine)

Verifying Persistent Variables

To confirm that a persistent variable was saved correctly in the Windows Registry without needing to restart your computer, retrieve it using GetEnvironmentVariable:

# Retrieve user-level variable
[System.Environment]::GetEnvironmentVariable('CUSTOM_KEY', 'User')

# Retrieve machine-level variable
[System.Environment]::GetEnvironmentVariable('CUSTOM_KEY', 'Machine')

Note that any PowerShell or Command Prompt windows opened before setting a persistent variable will not automatically detect the new variable; you must start a new terminal session to load updated environment values.

Deleting Custom Environment Variables

To remove an environment variable, set its value to $null or an empty string for the target scope.

  • Remove from current session:

    Remove-Item Env:\CUSTOM_KEY

  • Remove permanently from User scope:

    [System.Environment]::SetEnvironmentVariable('CUSTOM_KEY', $null, 'User')

  • Remove permanently from Machine scope (requires Administrator):

    [System.Environment]::SetEnvironmentVariable('CUSTOM_KEY', $null, 'Machine')
