User Profile Service Role in Windows 10 Logon

The User Profile Service (ProfSvc) is a core Windows 10 background service responsible for loading, unloading, and managing user profiles during authentication. When a user signs in, ProfSvc ensures that their personalized environment—including registry hives, personal folders, and configuration data—is properly mounted and accessible. Without this service, Windows cannot initialize a user's desktop session or apply individual settings.

When a user submits valid credentials, the Local Security Authority Subsystem Service (LSASS) authenticates the account and signals the Windows Logon Application (winlogon.exe). Winlogon then invokes the User Profile Service (ProfSvc) to prepare the user space.

ProfSvc first checks the Windows Registry under HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList to determine whether a profile already exists for the user's Security Identifier (SID). If it is a first-time sign-in, ProfSvc creates a new directory in C:\Users\ by copying templates and settings from the hidden Default profile directory. If an existing profile is found, the service verifies its integrity; if the profile is corrupted, ProfSvc either loads a temporary profile or rejects the logon with a service failure error.

Once the profile path is resolved, ProfSvc mounts the user's registry hive. It reads the NTUSER.DAT file located in the user's root folder and mounts it into the registry under HKEY_USERS\<SID>, establishing a symbolic link to HKEY_CURRENT_USER (HKCU). This step allows installed software and the Windows shell to read user-specific preferences, application states, and policies.

Next, ProfSvc configures environment variables (such as %USERPROFILE% and %APPDATA%) and validates access permissions to default known folders, such as Documents, Desktop, and Downloads. If Folder Redirection or roaming profiles are configured via Group Policy, ProfSvc synchronizes these network paths during this phase.

Finally, after successfully loading the hive and verifying directory permissions, ProfSvc notifies Winlogon that the environment is ready. Winlogon then launches userinit.exe, which applies Group Policies, executes startup scripts, and ultimately initiates the Windows shell (explorer.exe) to display the desktop. ProfSvc remains active in the background until the user signs out, at which point it unloads NTUSER.DAT and writes pending registry changes back to disk.
