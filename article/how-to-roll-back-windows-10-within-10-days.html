How to Roll Back Windows 10 Within 10 Days

When you install a major feature update on Windows 10, the operating system creates a built-in safety net that allows you to revert to your previous version within a strict 10-day window. This article explains the technical mechanics behind this feature, including how Windows preserves your previous operating system data, why the countdown exists, how the system executes the rollback process, and the exact steps to initiate it.

The Role of the Windows.old Folder

The recovery feature relies on an automated backup process executed during any major feature update. Before applying the new OS files, Windows moves the critical components of your previous installation into a hidden folder on your system drive named C:\Windows.old.

This directory contains:

  • The previous Windows system files and binaries (System32, drivers, etc.).
  • The previous Registry hives containing your system and user configurations.
  • The Program Files and ProgramData directories.
  • A snapshot of your user profiles (Users directory).

Windows also creates temporary tracking folders, such as $Windows.~BT and $Windows.~WS, which contain setup logs and installation media used to orchestrate the upgrade and facilitate the reversal.

The 10-Day Automated Deletion Mechanism

Originally set to 30 days in early versions of Windows 10, Microsoft reduced the rollback period to 10 days via the Anniversary Update. Telemetry showed that most users who encounter critical stability issues roll back within the first few days, and retaining the massive Windows.old directory (often 20 GB to 40 GB) unnecessarily consumed drive space.

A background maintenance task managed by Windows Task Scheduler monitors the creation timestamp of Windows.old. Once 10 days (240 hours) have elapsed, Windows runs automated disk cleanup routines—often tied to Storage Sense—to permanently delete the Windows.old folder. Once this folder is removed, the built-in option to roll back is permanently disabled.

What Happens During the Rollback Process

When you trigger the rollback mechanism, Windows executes the following technical sequence:

  1. System Reboot into Windows Recovery Environment (WinRE): The active OS unloads, and the computer boots into an isolated recovery environment to prevent file-locking conflicts.
  2. File Swap: WinRE replaces the current system binaries and configuration files with those stored inside Windows.old.
  3. Registry Restoration: The current Registry is replaced by the archived Registry hives from the previous build.
  4. Boot Configuration Update: The Boot Configuration Data (BCD) is rewritten to point to the restored operating system kernel.
  5. Cleanup: The updated OS files that were being tested are purged, and the system reboots directly into the prior version of Windows 10.

Personal documents, photos, and files stored in standard user folders are preserved. However, any programs installed, settings changed, or drivers updated after the upgrade are permanently removed.

How to Initiate the Rollback

To trigger the rollback while inside the 10-day window:

  1. Open Settings from the Start menu.
  2. Click on Update & Security.
  3. Select Recovery from the left-hand navigation pane.
  4. Locate the section titled Go back to the previous version of Windows 10 and click Get started.
  5. Select a reason for going back, decline the prompt to check for updates, and accept the warnings regarding app reinstallation and passwords.
  6. Click Go back to earlier build to begin the automated restoration process.
