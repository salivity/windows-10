What Is the Windows 10 DirectX Diagnostic Tool?

The DirectX Diagnostic Tool (DxDiag) is a built-in utility in the Microsoft Windows 10 operating system designed to collect detailed hardware specifications, diagnose audio and video problems, and test DirectX multimedia functionality. It provides users and support technicians with a comprehensive snapshot of a computer's graphical, sound, and input components, making it a critical tool for troubleshooting performance issues in video games and graphic-intensive applications.

Primary Functions of DxDiag

DxDiag serves three core purposes on Windows 10: system information gathering, hardware component verification, and troubleshooting log generation.

1. System Information Overview

Upon opening, the tool displays fundamental system data on the System tab. This includes:

  • The exact version and build of Windows 10.
  • Processor model and clock speed.
  • Installed system memory (RAM) and page file usage.
  • System BIOS and motherboard manufacturer.
  • The currently installed DirectX version (typically DirectX 12 on Windows 10).

2. Display and Graphics Diagnosis

The Display tab (or multiple tabs if using multiple monitors or GPUs) provides in-depth data regarding the system’s graphics hardware. It details:

  • The graphics processing unit (GPU) make, model, and device ID.
  • Dedicated Video RAM (VRAM) versus shared system memory.
  • Graphics driver versions, dates, and WHQL (Windows Hardware Quality Labs) certification status.
  • Acceleration status for DirectDraw, Direct3D, and AGP Texture features.
  • A "Notes" box at the bottom that flags any known device conflicts or driver errors.

3. Sound and Audio Device Verification

The Sound tab catalogs every active audio playback device, whether it is an integrated motherboard chip, a dedicated sound card, a USB headset, or HDMI audio via the GPU. It lists driver details, hardware IDs, and highlights missing or corrupted audio drivers.

4. Input Device Monitoring

The Input tab identifies human interface devices (HID) connected to the system, such as keyboards, mice, gamepads, and joysticks. It verifies that Windows properly detects these peripherals and registers their poll rates and drivers correctly.

Diagnostic Reporting and Support

Beyond live viewing, DxDiag includes a Save All Information feature. Clicking this button compiles all collected hardware data, driver versions, and detected errors into a standardized plain text file (DxDiag.txt). This report is universally used by customer support teams, game developers, and IT administrators to diagnose crashes, low frame rates, and hardware incompatibilities without requiring direct access to the user's machine.

How to Access DxDiag in Windows 10

The tool can be accessed quickly via the following steps:

  1. Press the Windows Key + R to open the Run dialog box.
  2. Type dxdiag and press Enter or click OK.
  3. If prompted to check for digitally signed drivers, select Yes.
