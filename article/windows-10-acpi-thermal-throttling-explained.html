Windows 10 ACPI Thermal Throttling Explained

The Microsoft Windows 10 operating system manages hardware temperatures by interfacing with system firmware via the Advanced Configuration and Power Interface (ACPI) specification. Through ACPI thermal zones, Windows abstracts the physical thermal sensors and cooling hardware of a device, enabling the OS to monitor live temperatures, respond to predefined thermal thresholds, and execute dynamic active or passive cooling policies—including CPU and GPU throttling—to maintain safe operating conditions.

Understanding ACPI Thermal Zones

An ACPI thermal zone is an abstracted partition of a computer system defined by the motherboard firmware (UEFI/BIOS). A single machine can have multiple thermal zones representing different physical regions, such as the CPU socket, discrete GPU, memory, or chassis skin.

Each thermal zone contains a set of standard ACPI objects (methods and values) that Windows 10 reads to understand the thermal topology:

  • _TMP (Temperature): Returns the current temperature of the zone in tenths of a Kelvin.
  • _PSV (Passive Cooling Threshold): The temperature at which the OS must initiate throttling to slow down heat generation.
  • _ACx (Active Cooling Thresholds): Temperatures at which active cooling devices (like fans) are turned on or sped up.
  • _CRT (Critical Trip Point): The temperature threshold where immediate shutdown occurs to protect against hardware damage.
  • _HOT (Hot Trip Point): The temperature at which Windows initiates a controlled critical transition, such as entering hibernation.

The Windows 10 Thermal Management Architecture

Windows 10 manages thermal zones through its native ACPI driver (acpi.sys) in conjunction with the system thermal driver (thermal.sys).

  1. Temperature Reporting: Windows monitors the _TMP value either through periodic polling or via ACPI event notifications (Notify(ThermalZone, 0x80)) sent from the embedded controller (EC) when temperature thresholds are crossed.
  2. Cooling Policy Application: The OS determines whether to apply an Active or Passive cooling policy based on current power plans and hardware capabilities. In Windows 10, cooling modes can be configured via power plan settings:
    • Active Cooling: The OS ramps up fan speeds (via _ACx objects) before reducing processor performance.
    • Passive Cooling: The OS prioritizes reducing processor speeds before ramping up fans to save power or reduce acoustic noise.

The Thermal Throttling Process

When a thermal zone’s current temperature (_TMP) exceeds the passive trip point (_PSV), Windows 10 initiates passive cooling, commonly known as thermal throttling.

  • Processor State Management: Windows reduces processor performance by altering processor P-states (Performance states) or utilizing Collaborative Processor Performance Control (CPPC). By lowering operating frequency and voltage (DVFS), power consumption drops, immediately reducing heat output.
  • Proportional Control Algorithm: Windows 10 employs an internal proportional-integral control algorithm. If the temperature continues to rise above _PSV, the OS throttles the CPU more aggressively. If the temperature drops below _PSV, performance states are gradually restored.
  • Processor Throttling Limits: If voltage and frequency scaling are insufficient to arrest temperature gains, the OS can invoke T-states (throttling states), which insert clock-stop idle cycles to drastically cut heat generation at the expense of computational performance.

Critical Safety Actions

If thermal throttling fails to stabilize temperatures and the zone reaches _HOT, Windows 10 saves user state and transitions the system into a low-power hibernation state. If temperatures reach _CRT, the OS bypasses graceful shutdown procedures and performs an immediate, hard power-off to ensure the physical integrity of the hardware.
