Purpose of Windows 10 Local Users and Groups

The Local Users and Groups manager in Windows 10 is an administrative utility designed to manage user credentials, security groups, and local access permissions on an individual computer. This article explains the primary functions of this configuration tool, how it enhances system security and access control, and which editions of Windows 10 support it.

Core Purpose of the Tool

The Local Users and Groups tool (accessible via lusrmgr.msc or within Computer Management) serves as a centralized Microsoft Management Console (MMC) snap-in for managing the security database of a standalone or workgroup computer. Its main objective is to define who can access the system and determine the extent of their permissions.

Primary Functions

  • User Account Management: Administrators can create, modify, disable, and delete local user accounts. The tool allows specific parameters to be set per user, such as forcing a password change at the next logon, preventing users from changing their own passwords, or setting account expiration dates.
  • Group Management: Instead of assigning permissions to individual users repeatedly, administrators organize users into groups (such as Administrators, Standard Users, Remote Desktop Users, or Guests). Rights assigned to a group automatically apply to all members assigned to that group.
  • Access Control and Security Enforcement: The tool enables the principle of least privilege by ensuring standard accounts only receive the access rights necessary for daily tasks, while elevated administrative rights remain restricted.
  • Password and Credential Control: Administrators can unlock locked-out accounts and reset local passwords directly without needing the user's prior credentials.

System Availability

The Local Users and Groups snap-in is available on business-oriented editions of Windows 10, including Windows 10 Pro, Enterprise, and Education. It is intentionally omitted from Windows 10 Home, where user management is handled through the basic Accounts menu in the Settings application or via command-line utilities.
