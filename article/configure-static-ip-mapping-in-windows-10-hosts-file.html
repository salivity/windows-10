Configure Static IP Mapping in Windows 10 Hosts File

The Windows 10 hosts file provides a local mechanism to override Domain Name System (DNS) resolutions by manually mapping static IP addresses to domain names. When an application attempts to connect to a domain, the operating system checks this local text file before querying external DNS servers. This guide details the function of the file, its location, and the direct steps required to configure custom static IP entries using administrative permissions.

Understanding the Hosts File

The hosts file is an operating system-level configuration file without a file extension. Because Windows checks the local hosts table first during network name resolution, an entry here forces traffic bound for a specific hostname to route to the defined IP address. This is commonly used for local web development, testing server migrations before updating public DNS, or blocking network access to specific domains by pointing them to local loopback addresses (such as 127.0.0.1 or 0.0.0.0).

File Location

In Windows 10, the file is stored in a protected system directory:

C:\Windows\System32\drivers\etc\hosts

Because this directory is protected by Windows User Account Control (UAC), direct modification requires elevated administrative privileges.

Steps to Configure Static IP Mapping

  1. Launch a Text Editor as Administrator
    Click the Start menu, type Notepad, right-click the Notepad application from the search results, and select Run as administrator. Confirm the User Account Control (UAC) prompt if prompted.

  2. Open the Hosts File
    In Notepad, select File > Open. Navigate to C:\Windows\System32\drivers\etc. In the bottom-right corner of the open file dialog, change the file type filter from **Text Documents (.txt) to All Files (.*). Select the hosts file and click Open**.

  3. Add the Static IP Mapping
    Scroll to the bottom of the file. Add a new line using the standard syntax: the target IP address, followed by at least one space or tab, followed by the domain name. Comments can be appended using the # symbol.

    Syntax:

    [IP Address] [Domain Name]

    Examples:

    # Map a local development server
192.168.1.50    dev.example.local

# Point a public domain to a specific testing server
203.0.113.10    example.com www.example.com

  4. Save the Changes
    Select File > Save (or press Ctrl + S). Ensure the file is saved with its original name without an extension (do not save it as hosts.txt).

  5. Flush the DNS Cache
    While changes to the hosts file typically take effect immediately, Windows may retain previously resolved addresses in its local cache. To ensure the new mapping is active:

    • Open the Start menu, type cmd, and open the Command Prompt.
    • Run the command: ipconfig /flushdns
    • Press Enter.

Once completed, any local application, such as a web browser or terminal tool, will route requests for the specified hostnames directly to the configured static IP addresses.
