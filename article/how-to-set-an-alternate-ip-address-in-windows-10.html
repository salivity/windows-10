How to Set an Alternate IP Address in Windows 10

Windows 10 includes a built-in networking feature known as Alternate Configuration, which allows a network adapter to automatically switch to a static IP address if a dynamic IP address (DHCP) server cannot be reached. This article explains how the operating system handles this failover mechanism and provides a direct, step-by-step guide to configuring an alternate static IP via the TCP/IPv4 properties menu.

How Alternate Configuration Works

By default, network adapters set to receive an IP address automatically will generate an Automatic Private IP Addressing (APIPA) address (in the range of 169.254.0.1 to 169.254.255.254) when a DHCP server does not respond. When the Alternate Configuration feature is enabled, Windows 10 replaces this automatic APIPA fallback with user-defined static parameters.

Upon connecting to a network, Windows 10 first broadcasts DHCP discover packets. If a DHCP server responds, the dynamically assigned settings are applied. If the request times out without a response, the operating system bypasses APIPA and applies the predefined static IP address, subnet mask, default gateway, and DNS servers. This is particularly useful for devices moving between networks with DHCP (like a home or office network) and networks with static IP requirements (like an industrial or lab environment).

Steps to Configure an Alternate Static IP Address

To configure this setting, the primary network configuration must be set to obtain an IP address automatically. Follow these steps:

  1. Open Network Connections: Press Windows Key + R, type ncpa.cpl, and press Enter to open the Network Connections window.

  2. Access Adapter Properties: Right-click the network adapter you want to configure (Ethernet or Wi-Fi) and select Properties.

  3. Open IPv4 Properties: Under the Networking tab, locate and select Internet Protocol Version 4 (TCP/IPv4), then click the Properties button.

  4. Verify General Settings: On the General tab, ensure that Obtain an IP address automatically is selected. The Alternate Configuration tab will only appear if dynamic addressing is selected on the General tab.

  5. Access Alternate Configuration: Click the Alternate Configuration tab at the top of the window.

  6. Enter Static Network Information: Select the User configured radio button to unlock the static entry fields, then enter your desired parameters:

    • IP address: Enter the static IPv4 address.
    • Subnet mask: Enter the appropriate subnet mask.
    • Default gateway: Enter the router or gateway address.
    • Preferred DNS server: Enter the primary DNS address.
    • Alternate DNS server: Enter an optional secondary DNS address.

  7. Save the Configuration: Click OK on the TCP/IPv4 Properties window, then click Close on the adapter properties window to apply the settings.

Windows 10 will now dynamically connect to any active DHCP network, but will smoothly default to these defined static parameters whenever a DHCP server is unavailable.
