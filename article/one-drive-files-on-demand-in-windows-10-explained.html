OneDrive Files On-Demand in Windows 10 Explained

Microsoft Windows 10 deeply integrates cloud storage through OneDrive Files On-Demand, a feature that allows users to access their entire OneDrive library directly from File Explorer without consuming local disk space. This article explores how Windows 10 natively handles cloud files, the underlying file-system mechanisms that make this possible, the different file states used by the operating system, and how the feature works in tandem with Windows storage management tools.

Core Architecture and the Cloud Filter API

OneDrive Files On-Demand relies on the Windows Cloud Filter API, introduced in the Windows 10 Fall Creators Update. Instead of simply synchronizing entire folders by downloading every file locally, the operating system uses NTFS file system metadata to create lightweight placeholders.

These placeholders mimic full files: they retain standard file attributes such as names, sizes, extensions, and timestamps, allowing them to appear and behave like physical files within File Explorer. When an application attempts to open an online-only placeholder, the file system minifilter driver intercepts the read command, transparently requests the file data from the OneDrive service, downloads the content in real time, and passes it back to the requesting application without interruption.

The Three File Availability States

Windows 10 visually communicates the status of each cloud-integrated file through dynamic status icons displayed in File Explorer:

  • Online-Only Files (Blue Cloud Icon): These files exist entirely in Microsoft’s cloud. They consume zero bytes of local hard drive space and contain only local metadata. A connection to the internet is required to open them, at which point Windows downloads the data automatically.
  • Locally Available Files (Green Checkmark in a White Circle): When an online-only file is opened, Windows downloads it to local storage. It remains cached locally so it can be opened without an internet connection. If disk space runs low, the operating system can purge the local copy back to an online-only state while retaining the metadata.
  • Always Available Files (White Checkmark in a Solid Green Circle): Users can explicitly pin files or folders by right-clicking them and selecting "Always keep on this device." Windows downloads these files permanently, ensuring offline availability. These files are never automatically removed by the operating system during storage cleanups.

System Integration and Storage Sense

The integration extends beyond File Explorer to Windows 10’s automated maintenance systems. Through the Storage Sense utility, the operating system can actively manage local storage without user intervention. Users can configure policies that automatically revert locally cached files back to online-only placeholders if they have not been accessed within a specified period (such as 14, 30, or 60 days).

Because the integration occurs at the operating system level, cloud files fully support standard Windows desktop features. Users can search for online-only files using Windows Search, drag and drop them between local applications, and secure them using standard Windows access controls.
