Configure Network Throttling Index in Windows 10

Windows 10 employs a built-in network throttling mechanism designed to prioritize multimedia playback and prevent network-intensive tasks from degrading audio and video performance. This mechanism is governed by the NetworkThrottlingIndex parameter in the Windows Registry, which restricts the processing rate of non-multimedia network packets when multimedia applications are active. This guide explains how the operating system implements this parameter, its default behavior, and the precise steps required to modify or disable it for improved network throughput and lower latency.

How Windows 10 Uses Network Throttling

The Network Throttling Index is managed by the Multimedia Class Scheduler Service (MMCSS). When an application utilizes MMCSS to process multimedia streams, Windows 10 limits the handling of standard network packets to reserve CPU time for uninterrupted playback.

By default, the operating system assigns a decimal value of 10 to this parameter. This setting restricts the system to processing a maximum of 10 network packets per millisecond (approximately 10,000 packets per second) per network interface. While this prevents audio stuttering on resource-constrained hardware, it can inadvertently introduce latency, packet buffering, or throughput caps in high-performance network scenarios such as online gaming or local high-speed file transfers.

Registry Location and Parameter Values

The network throttling configuration is stored within the Windows Registry at the following path:

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile

Within this key, the setting is defined by a 32-bit DWORD entry named NetworkThrottlingIndex. The operating system interprets the data assigned to this entry as follows:

  • Default Value (10 in Decimal / 0x0000000a in Hexadecimal): Restricts non-multimedia traffic to 10 packets per millisecond while multimedia playback is detected.
  • Custom Values (1 to 70 in Decimal): Sets an explicit packet processing limit per millisecond corresponding to the defined integer.
  • Disabled Throttling (ffffffff in Hexadecimal / 4294967295 in Decimal): Completely disables the network throttling mechanism. The network adapter processes packets at maximum capability regardless of multimedia application activity.

Steps to Configure the Network Throttling Index

To modify how Windows 10 handles this throttling parameter, use the Windows Registry Editor:

  1. Press Windows Key + R, type regedit into the Run dialog box, and press Enter to open the Registry Editor.
  2. In the address bar at the top of the Registry Editor, navigate to: HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile
  3. Locate the NetworkThrottlingIndex entry in the right-hand pane.
  4. Double-click NetworkThrottlingIndex to edit its properties.
  5. In the Edit DWORD (32-bit) Value window:
    • To disable throttling entirely, select the Hexadecimal base and enter ffffffff into the Value data field.
    • To restore the default configuration, select the Decimal base and enter 10.
    • To apply a custom limit, select the Decimal base and enter a value between 1 and 70.
  6. Click OK to commit the change.
  7. Close the Registry Editor and restart your computer to apply the updated network throttling configuration.
