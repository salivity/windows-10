Windows 10 Network Adapter Priority and Metrics

When a Windows 10 device connects to multiple networks simultaneously—such as Ethernet, Wi-Fi, and a cellular or VPN connection—the operating system must determine which path outbound internet traffic should take. Windows 10 manages this network hierarchy using a routing cost mechanism known as a metric, calculated via an automated process called the Automatic Metric feature. This article outlines how Windows calculates these interface metrics, how route selection occurs, and how administrators can manually configure priority order when needed.

The Concept of Network Metrics

In TCP/IP routing, a metric is an integer assigned to a specific IP route or interface. It represents the cost of using that network path. Windows assigns metrics to network interfaces based on their overall performance characteristics.

The core rule of IP routing in Windows is simple: the lower the metric value, the higher the priority. If two active adapters have default routes to the internet, Windows sends outbound traffic through the adapter with the lowest combined interface and gateway metric.

The Automatic Metric Feature

By default, Windows 10 enables the Automatic Metric feature on all network interfaces. This feature dynamically configures the metric based on the reported link speed of the adapter.

When an interface connects, Windows measures its current link speed and assigns a predefined metric:

  • Link speeds greater than 200 Mbps (e.g., Gigabit Ethernet): Metric 10
  • Link speeds between 80 Mbps and 200 Mbps: Metric 20
  • Link speeds between 20 Mbps and 80 Mbps: Metric 25
  • Link speeds between 4 Mbps and 20 Mbps: Metric 30
  • Link speeds between 500 Kbps and 4 Mbps: Metric 40
  • Link speeds under 500 Kbps: Metric 50

Because wired Ethernet connections usually provide higher link speeds than Wi-Fi, Windows automatically assigns Ethernet a lower metric, making it the preferred default gateway without requiring user intervention. If an Ethernet cable is disconnected, the routing table updates immediately, and traffic reroutes to the next lowest metric interface, such as Wi-Fi.

How the Routing Table Determines Priority

Windows 10 determines the path for packets by consulting its internal routing table. Each default route (0.0.0.0/0) in the table has an associated cost composed of:

  1. The Gateway Metric: Typically assigned by DHCP or set to 0 or 1.
  2. The Interface Metric: Determined by the link speed (or set manually).

The effective metric is the sum of these two values. When an application initiates a network request to an external IP, the TCP/IP stack selects the route with the lowest overall metric. If two adapters have identical total metrics, Windows may use round-robin load distribution or choose the first binding adapter.

Manually Configuring Adapter Priority

There are scenarios where the default behavior is undesirable, such as when a slower wired connection must take precedence over high-speed Wi-Fi, or when a specific VPN interface needs priority. Administrators can override the Automatic Metric using either the graphical interface or PowerShell.

Method 1: Using the Graphical Interface

  1. Press Win + R, type ncpa.cpl, and press Enter to open Network Connections.
  2. Right-click the preferred adapter and select Properties.
  3. Select Internet Protocol Version 4 (TCP/IPv4) and click Properties.
  4. Click the Advanced button in the lower-right corner.
  5. In the IP Settings tab, uncheck the Automatic metric box.
  6. In the Interface metric field, enter a low number (e.g., 5 to force high priority, or 100 to force low priority).
  7. Click OK on all open windows to apply the changes.

Method 2: Using PowerShell

Windows PowerShell allows network metrics to be viewed and changed directly via the NetTCPIP module.

To view current metrics:

Get-NetIPInterface | Select-Object IfIndex, InterfaceAlias, InterfaceMetric, AutomaticMetric

To assign a manual metric, identify the interface index (IfIndex) or name and run:

Set-NetIPInterface -InterfaceIndex <IndexNumber> -AutomaticMetric Disabled -InterfaceMetric 5

Setting a low value ensures that Windows 10 consistently routes traffic through that designated interface whenever it is connected, bypassing the dynamic link-speed evaluation.
