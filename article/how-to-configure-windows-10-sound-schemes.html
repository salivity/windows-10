How to Configure Windows 10 Sound Schemes

This article explains how the Microsoft Windows 10 operating system manages and customizes system audio cues, including notification chimes and event alerts. It details the step-by-step process of accessing audio settings through both the classic Control Panel and the modern Settings app, modifying individual event sounds, creating custom sound schemes using audio files, and managing notification behaviors for specific applications.

Accessing the Sound Control Panel

While Windows 10 features a modern Settings app, full control over system sound schemes and specific event chimes resides within the legacy Sound Control Panel.

  1. Press Windows Key + R to open the Run dialog box.
  2. Type mmsys.cpl and press Enter (or navigate to Settings > System > Sound and click Sound Control Panel under Related Settings).
  3. In the Sound window that appears, click the Sounds tab.

Customizing System Event Sounds

Under the Sounds tab, Windows lists every system event capable of playing audio in the Program Events box.

  1. Scroll through the Program Events list and select the specific trigger you want to modify, such as Notification, Default Beep, or Critical Stop.
  2. Click the Sounds drop-down menu at the bottom of the window to choose a pre-installed audio tone.
  3. To listen to the selected sound, click the Test button.
  4. To use a custom audio file, click Browse... and select any .wav file stored on your computer (Windows only accepts uncompressed .wav formats for system events).
  5. If you prefer silence for a specific event, select (None) from the top of the Sounds drop-down menu.

Saving or Switching Sound Schemes

A sound scheme is an active profile containing all configured event sounds across the operating system.

  • Switching Schemes: Use the Sound Scheme drop-down menu to switch between default presets, such as Windows Default or No Sounds.
  • Saving Custom Schemes: After customizing individual event sounds, click the Save As... button next to the Sound Scheme drop-down. Enter a name for your custom profile and click OK.
  • Applying Changes: Click Apply, then OK to activate the new configuration.

Managing Notification Chimes by Application

Windows 10 also allows you to control whether individual apps play chimes when delivering banner notifications.

  1. Open Settings (press Windows Key + I).
  2. Go to System > Notifications & actions.
  3. Under Get notifications from these senders, click the specific application you wish to adjust.
  4. Toggle the switch for Play a sound when a notification arrives to either On or Off.
