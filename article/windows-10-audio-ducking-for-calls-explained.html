Windows 10 Audio Ducking for Calls Explained

Audio ducking is an automated feature in Windows 10 that lowers the volume of background media—such as music, browser audio, or games—whenever an active voice or video call is detected. This article explains how the Windows 10 operating system identifies communication streams through its Core Audio APIs, the mechanisms it uses to attenuate non-communication audio, and how users can customize or completely disable this feature.

How Windows 10 Identifies Communication Streams

Windows 10 manages audio ducking via the Windows Audio Session API (WASAPI). When a software application like Microsoft Teams, Skype, Zoom, or Discord initiates a call, it registers its audio stream with an explicit role: eCommunications.

The operating system monitors all active audio sessions. When a stream tagged with the communication role begins capturing (microphone input) or rendering (voice output) audio, the Windows audio engine flags the system as entering an active communication state. This triggers the system-wide ducking experience.

The Ducking Mechanism (Audio Attenuation)

Once an active communication session is established, the Windows Multimedia Device (MMDevice) API applies attenuation to all other audio sessions on the same rendering endpoint. By default:

  • The communication stream maintains 100% of its normal output volume.
  • Background streams (tagged as eConsole or eMultimedia, such as Spotify, YouTube, or PC games) are attenuated automatically.
  • The transition is smooth; Windows applies a brief fade-out to lower the volume rather than cutting it abruptly. When the call ends and the communication stream closes, Windows fades the background audio back to its original level.

Third-party developers can also implement custom ducking behavior within their applications using the IAudioVolumeDuckNotification interface, allowing apps to opt out of system ducking or handle volume suppression internally.

Default Options in Windows 10

Windows 10 provides four built-in profiles for handling non-call audio during a voice call:

  1. Mute all other sounds: Completely silences any application not marked as a communication stream.
  2. Reduce the volume of other sounds by 80%: The default setting in Windows 10, which sharply reduces background audio so speech is clearly audible.
  3. Reduce the volume of other sounds by 50%: A moderate reduction suitable for users who still need to hear secondary audio clearly.
  4. Do nothing: Disables audio ducking entirely, leaving all non-communication applications at their existing volume levels.

How to Configure or Disable Audio Ducking

Users can change how Windows 10 handles call attenuation through the legacy Sound Control Panel:

  1. Press Windows Key + R, type mmsys.cpl, and press Enter.
  2. In the Sound window, click the Communications tab.
  3. Select your preferred action (e.g., select Do nothing to turn off ducking).
  4. Click Apply, then OK.

Changes take effect immediately for subsequent calls, preventing unexpected volume drops during gaming, streaming, or multitasking.
