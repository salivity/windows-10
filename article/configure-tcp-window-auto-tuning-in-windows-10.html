Configure TCP Window Auto-Tuning in Windows 10

TCP window auto-tuning is a core networking feature in Windows 10 designed to dynamically adjust the Receive Window (RWIN) size to optimize throughput across varying network conditions. This article explains what TCP auto-tuning levels are, details the different states available in the operating system, and provides step-by-step instructions on how to check and configure these settings using command-line tools.

Understanding TCP Window Auto-Tuning Levels

TCP window auto-tuning enables the operating system to continuously monitor bandwidth-delay product (BDP) and network latency, automatically adjusting the TCP receive buffer to maximize data transfer rates.

Windows 10 provides five distinct auto-tuning levels:

  • Disabled: Sets the TCP receive window to its default fixed limit (typically 64 KB) and disables RFC 1323 window scaling. This can resolve compatibility issues with older, non-compliant network hardware but severely caps throughput on high-speed internet connections.
  • Highlyrestricted: Allows the receive window to scale beyond the default limit, but does so very conservatively to prevent throughput instability on constrained networks.
  • Restricted: Permits moderate window scaling, growing the receive window more conservatively than the default setting.
  • Normal (Default): The standard operating mode. It allows the receive window to grow dynamically to accommodate almost all modern network scenarios, maximizing throughput based on measured latency and bandwidth.
  • Experimental: Allows the receive window to expand aggressively to extreme values. This setting is intended for high-latency, massive-bandwidth environments (such as long-haul research links) and may cause connection instability on standard consumer networks.

How to Check the Current Auto-Tuning Level

To view the active TCP auto-tuning configuration on Windows 10:

  1. Right-click the Start button and select Windows PowerShell (Admin) or Command Prompt (Admin).
  2. Run the following command:
netsh interface tcp show global
  1. Locate the entry named Receive Window Auto-Tuning Level. The value next to it indicates your current setting (typically normal).

How to Configure the Auto-Tuning Level

Changing the auto-tuning level requires administrative privileges. Open an elevated PowerShell or Command Prompt window and execute the appropriate command based on your requirements:

  • To restore the default setting (recommended):

    netsh interface tcp set global autotuninglevel=normal

  • To disable auto-tuning:

    netsh interface tcp set global autotuninglevel=disabled

  • To set auto-tuning to restricted:

    netsh interface tcp set global autotuninglevel=restricted

  • To set auto-tuning to highly restricted:

    netsh interface tcp set global autotuninglevel=highlyrestricted

  • To set auto-tuning to experimental:

    netsh interface tcp set global autotuninglevel=experimental

After running the command, the console should return an Ok. message. The changes take effect immediately for new TCP connections without requiring a system reboot.
