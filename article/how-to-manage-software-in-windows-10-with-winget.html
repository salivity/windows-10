How to Manage Software in Windows 10 with Winget

Windows Package Manager, known as winget, is a native command-line tool in Windows 10 designed to automate and streamline software installation, upgrading, configuration, and removal. This article explains how winget operates within Windows 10, covers its essential commands for managing applications from trusted repositories, and highlights how it eliminates the need for manual executable downloads and setup wizards.

What is Windows Package Manager?

Windows Package Manager (winget) functions as a unified package manager for Windows 10, similar to package managers found in Linux environments (such as apt or pacman) and macOS (Homebrew). Built into Windows 10 via the Microsoft Store’s "App Installer" package, winget allows users and system administrators to query software repositories, download verified application installers, and run unattended installations directly from PowerShell or the Command Prompt.

How Winget Works Under the Hood

When a command is executed, winget interacts with curated repositories—primarily the official Microsoft Community Repository and the Microsoft Store.

  1. Manifest Validation: Software packages are defined by YAML manifests containing metadata, source URLs, installer types (such as EXE, MSI, or MSIX), silent install switches, and SHA-256 cryptographic hashes.
  2. Integrity and Security Checks: Before launching an installer, winget checks the file's hash against the manifest to verify that the downloaded binary has not been tampered with. Microsoft also runs automated SmartScreen and antivirus scanning on submitted packages.
  3. Execution: Winget passes vendor-specific silent installation arguments to the installer, enabling applications to install in the background without user prompts.

Key Commands for Software Management

Managing applications with winget requires only a few core commands executed in PowerShell or Command Prompt.

1. Searching for Applications

To find an application, query the repository using a keyword or the exact application name:

winget search <application-name>

The output displays the application name, unique package ID, version, and the source repository.

2. Installing Software

To install an application, reference either its common name or its unique package ID (recommended for precision):

winget install --id <Package.ID>

For example, running winget install --id Mozilla.Firefox downloads and silently installs Firefox with default settings.

3. Listing Installed Software

To view software installed on the system, including traditional desktop applications and Microsoft Store apps:

winget list

This command compares installed versions against the repository to determine whether updates are available.

4. Updating Applications

Winget can check for and apply updates across the entire system. To view available updates:

winget upgrade

To update a specific program:

winget upgrade --id <Package.ID>

To update all installed applications that have available updates in the repository:

winget upgrade --all

5. Uninstalling Software

Applications can be removed silently using:

winget uninstall --id <Package.ID>

Batch Management and System Provisioning

Winget provides export and import capabilities for rapid machine provisioning. A user can export their current software configuration into a JSON file:

winget export -o packages.json

On a fresh Windows 10 installation, running the import command installs every application listed in that file automatically:

winget import -i packages.json

This feature makes winget an efficient tool for deploying standardized software environments across multiple Windows 10 machines.
