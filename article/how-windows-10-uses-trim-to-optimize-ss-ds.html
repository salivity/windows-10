How Windows 10 Uses TRIM to Optimize SSDs

This article explains how the Microsoft Windows 10 operating system utilizes the TRIM command to maintain solid-state drive (SSD) speed and prolong drive lifespan. You will learn the mechanics of how SSDs write and delete data, what the TRIM command specifically instructs the drive controller to do, how Windows 10 schedules and executes these commands, and the role TRIM plays in background garbage collection.

The Underlying Challenge of SSD Storage

Traditional mechanical hard drives can easily overwrite existing data with new data in a single operation. Solid-state drives cannot. SSDs store data on NAND flash memory divided into individual pages, which are grouped into larger blocks. While an SSD can read and write data at the page level, it can only erase data at the block level.

When a file is deleted in an operating system, the system merely marks the file's index entry as free space rather than immediately wiping the raw flash memory. Without communication between the OS and the SSD, the drive controller still considers those pages to contain valid data. When new data needs to be written to a full drive, the SSD must execute a time-consuming "read-modify-write" cycle: it reads the entire block into a cache, erases the physical block, modifies the data, and writes it back. This causes write amplification, increases wear on the flash cells, and drastically reduces write speeds over time.

What the TRIM Command Does

TRIM is a standardized ATA and NVMe command that bridges the communication gap between the operating system and the SSD controller. When you delete a file, empty the Recycle Bin, or format a partition, Windows 10 sends a TRIM command directly to the SSD firmware.

This command informs the SSD precisely which logical block addresses (LBAs) no longer contain valid user data. Instead of waiting for a future write operation to discover that the space is obsolete, the SSD immediately knows those pages are invalid.

How Windows 10 Executes TRIM

Windows 10 employs a two-tiered approach to execute TRIM:

  1. Real-Time Deletion Notification: When an application or user deletes a file on an NTFS or ReFS volume, Windows 10 flags the operation and sends a real-time TRIM notification to the storage controller. This registers the marked sectors as invalid in the drive’s mapping table.
  2. Scheduled Optimization (Drive Defragmenter): Windows 10 includes a built-in maintenance utility known as "Optimize Drives." While the utility defragments mechanical drives, it detects SSDs and runs a comprehensive re-TRIM operation instead. By default, this maintenance task runs automatically on a weekly schedule. It sweeps the entire file system, detects any freed blocks that may have been missed during heavy I/O operations, and re-issues TRIM commands to guarantee the drive is fully optimized.

TRIM and Garbage Collection

TRIM does not physically wipe data the exact millisecond the command is received; doing so would tie up controller resources and degrade system responsiveness. Instead, TRIM works in tandem with the SSD’s native Garbage Collection algorithm.

Garbage Collection is an internal drive process that cleans up and reorganizes blocks in the background. Because Windows 10’s TRIM command has already tagged defunct pages as invalid, the SSD's garbage collection skips copying those invalid pages during block reorganization. The controller gathers the remaining valid pages, consolidates them into a new block, and wipes the old block clean. This ensures that a pool of empty blocks is always available for immediate, high-speed writes.

Verifying TRIM Status in Windows 10

Windows 10 enables TRIM by default on detected solid-state media. You can verify that TRIM is active through the Windows Command Prompt (run as Administrator) using the following command:

fsutil behavior query DisableDeleteNotify

  • If the result for NTFS or ReFS is 0, TRIM is enabled and actively working.
  • If the result is 1, TRIM is currently disabled.

Through continuous real-time signaling and scheduled maintenance sweeps, Windows 10 ensures SSDs maintain peak sequential and random write performance while minimizing drive wear over their operational lifespan.
