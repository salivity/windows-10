Configure Custom Pagefile Size in Windows 10

Windows 10 manages virtual memory using a dedicated hidden file named pagefile.sys, which acts as an extension of physical RAM when system memory is depleted. By default, Windows dynamically manages the size of this file, but administrators can establish custom minimum (initial) and maximum size thresholds. This guide explains how the operating system utilizes these thresholds and details the exact steps required to configure them manually.

How Windows 10 Uses Pagefile Thresholds

When you configure a custom pagefile, Windows 10 enforces two distinct boundaries:

  • Initial Size (Minimum Threshold): This is the baseline amount of disk space Windows immediately allocates to pagefile.sys upon system boot. Setting an adequate initial size prevents the operating system from constantly expanding the file during standard workloads, reducing disk fragmentation.
  • Maximum Size (Maximum Threshold): This represents the hard upper limit to which the pagefile can dynamically expand under heavy memory pressure. If the combined capacity of physical RAM and this maximum limit is exhausted, Windows will generate out-of-memory errors and may terminate unstable applications.

Steps to Configure Custom Thresholds in Windows 10

  1. Press Windows Key + R to open the Run dialog box.
  2. Type sysdm.cpl and press Enter to open System Properties.
  3. Navigate to the Advanced tab.
  4. Under the Performance section, click the Settings button.
  5. In the Performance Options window, switch to the Advanced tab.
  6. Under the Virtual memory section, click Change....
  7. Uncheck the option labeled Automatically manage paging file size for all drives.
  8. Select the drive volume (typically C:) where you want the paging file to reside.
  9. Select the Custom size radio button.
  10. Enter your desired values in megabytes (MB):
    • Initial size (MB): The minimum baseline capacity.
    • Maximum size (MB): The upper allocation limit.
  11. Click the Set button to register the changes.
  12. Click OK across all open dialog windows and restart your computer to apply the new memory configuration.

Sizing Considerations

A common practice for stability is to set the Initial size and Maximum size to the exact same value. This locks pagefile.sys to a static size on the drive, eliminating dynamic resizing operations and preventing file fragmentation on traditional hard drives. Standard guidelines recommend an initial size of 1.5 times your physical RAM and a maximum size of up to 3 times your physical RAM, though systems with large amounts of RAM (16 GB or higher) generally require significantly less.
