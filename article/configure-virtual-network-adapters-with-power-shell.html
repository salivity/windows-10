Configure Virtual Network Adapters with PowerShell

This article explains how the Microsoft Windows 10 operating system configures virtual network adapters using built-in PowerShell cmdlets. By utilizing the Hyper-V module and the NetAdapter/NetTCPIP modules, administrators can automate the creation, binding, addressing, and advanced configuration of virtual network interface cards (vNICs) for both the host management operating system and guest virtual machines without relying on graphical user interfaces.

Prerequisites

To manage virtual network adapters using PowerShell in Windows 10, the Hyper-V feature must be enabled. PowerShell must also be launched with elevated administrator privileges. The core cmdlets reside within the Hyper-V and NetAdapter modules.

1. Identifying Existing Switches and Adapters

Before configuring a virtual adapter, verify existing virtual switches and physical network interfaces:

# View all available virtual switches
Get-VMSwitch

# View existing virtual network adapters on the host and VMs
Get-VMNetworkAdapter -All

2. Creating and Attaching a Virtual Switch

A virtual network adapter requires a virtual switch to route traffic. If one does not already exist, create an external, internal, or private virtual switch:

# Create an Internal switch (for host-to-VM communication)
New-VMSwitch -Name "InternalSwitch" -SwitchType Internal

# Create an External switch (bound to a physical Ethernet adapter)
New-VMSwitch -Name "ExternalSwitch" -NetAdapterName "Ethernet" -AllowManagementOS $true

3. Adding a Virtual Network Adapter

You can add a virtual network adapter either to a specific virtual machine or directly to the Windows 10 host management OS.

To add a vNIC to a Virtual Machine:

Add-VMNetworkAdapter -VMName "TargetVM" -Name "VM_vNIC1" -SwitchName "InternalSwitch"

To add a vNIC directly to the Management OS (Host):

Add-VMNetworkAdapter -ManagementOS -Name "Host_vNIC1" -SwitchName "InternalSwitch"

4. Configuring Advanced Adapter Settings

Windows 10 provides cmdlets to modify network adapter capabilities, such as MAC address spoofing, bandwidth limits, and VLAN identification.

Enabling MAC Spoofing and Setting Bandwidth Limits:

Set-VMNetworkAdapter -VMName "TargetVM" -Name "VM_vNIC1" -MacAddressSpoofing On -MinimumBandwidthAbsolute 10000000

Configuring VLAN Tagging:

# Configure the adapter for Access mode on VLAN 20
Set-VMNetworkAdapterVlan -VMName "TargetVM" -VMNetworkAdapterName "VM_vNIC1" -Access -VlanId 20

# Configure the Management OS adapter for a specific VLAN
Set-VMNetworkAdapterVlan -ManagementOS -VMNetworkAdapterName "Host_vNIC1" -Access -VlanId 10

5. Configuring IP Address and DNS (NetTCPIP Module)

Once the virtual adapter is active in Windows 10, configure its Layer 3 IP addressing using the standard NetTCPIP cmdlets:

# Assign a static IPv4 address and default gateway
New-NetIPAddress -InterfaceAlias "vEthernet (Host_vNIC1)" -IPAddress 192.168.10.50 -PrefixLength 24 -DefaultGateway 192.168.10.1

# Configure DNS server addresses
Set-DnsClientServerAddress -InterfaceAlias "vEthernet (Host_vNIC1)" -ServerAddresses ("192.168.10.1", "8.8.8.8")

6. Removing a Virtual Network Adapter

To decommission and remove a virtual network adapter, use the Remove-VMNetworkAdapter cmdlet:

# Remove a vNIC from a virtual machine
Remove-VMNetworkAdapter -VMName "TargetVM" -Name "VM_vNIC1"

# Remove a vNIC from the management OS
Remove-VMNetworkAdapter -ManagementOS -Name "Host_vNIC1"
