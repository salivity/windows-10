How to Share Folders on a Windows 10 Home Network

Sharing folders across a local network in Microsoft Windows 10 relies on a combination of network profiles, share permissions, and local file system security. This article explains how Windows 10 enables folder sharing, breaking down the essential network discovery settings, the differences between basic and advanced sharing, and the interaction between Share permissions and NTFS permissions to ensure secure data access across devices.

1. Network Profile and Discovery Configuration

Before individual folders can be accessed by other devices, Windows 10 requires the local network connection to be configured correctly in the settings:

  • Private Network Profile: Windows defaults to a "Public" profile for security, which blocks inbound sharing. The active network must be set to "Private" under Settings > Network & Internet > Status > Properties.
  • Network Discovery and File Sharing: In the classic Control Panel under Network and Sharing Center > Advanced sharing settings, two key options must be turned on for the Private profile: Turn on network discovery (allows devices to see each other) and Turn on file and printer sharing (enables the Server Message Block, or SMB, protocol to accept inbound traffic).

2. Basic Sharing vs. Advanced Sharing

Windows 10 provides two methods to make a directory accessible over the network:

  • Basic Sharing: Right-clicking a folder, selecting Give access to, and choosing Specific people allows you to grant read or read/write access to specific local user accounts or to "Everyone." This method automatically configures baseline security settings behind the scenes.
  • Advanced Sharing: Accessed via the folder’s Properties > Sharing tab > Advanced Sharing, this method provides granular control. Administrators can set a custom share name, limit the number of simultaneous network connections, and manually assign Share Permissions (Full Control, Change, or Read) to specific users or groups.

3. Share Permissions vs. NTFS Permissions

Windows 10 uses a two-tier permission architecture when sharing folders over a network:

  • Share Permissions: Located on the Sharing tab, these govern access to the folder specifically through the network pipeline via SMB.
  • NTFS (Security) Permissions: Located on the Security tab, these govern access to the underlying storage volume on the physical drive, applying both locally and over the network.

When a user accesses a shared folder from another computer, Windows evaluates both permission sets. The most restrictive rule always applies. For example, if a user has "Full Control" in Share Permissions but only "Read" permission under the Security (NTFS) tab, they will only be able to view files, not edit or delete them.

4. Authentication and Password Protection

By default, Windows 10 enforces Password protected sharing (found in Advanced Sharing Settings). Under this setup:

  • The remote user must authenticate using the username and password of an existing local account on the host machine.
  • If a single common account is not desired, the host user can create dedicated standard user accounts on the machine solely for granting network access.
  • Disabling password protection allows any device on the network to access folders shared with the "Everyone" group without logging in, which reduces security and is generally not recommended.
