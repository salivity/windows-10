Windows 10 Telemetry Levels: Security to Full

Microsoft Windows 10 uses built-in diagnostic telemetry to monitor device health, remediate security vulnerabilities, and improve operating system performance. This article explains how Windows 10 processes telemetry data across its four primary tiers—Security, Basic, Enhanced, and Full. You will learn what specific system information each level collects, how user privacy is managed, and which Windows 10 editions support specific settings.

What is Windows 10 Telemetry?

Windows 10 telemetry refers to the automated transmission of technical and system diagnostic data from user devices to Microsoft. Transmitted via the Connected User Experiences and Diagnostic Data Service, this data helps Microsoft detect bugs, monitor software stability, and issue timely patches. Windows 10 manages this data through four distinct levels, ordered from least to most data shared: Security, Basic, Enhanced, and Full.

Level 0: Security

The Security level gathers the absolute minimum telemetry required to keep the Windows operating system and its active defenses updated and functional.

  • Target Availability: Restricted strictly to Windows 10 Enterprise, Windows 10 Education, Windows 10 IoT, and Windows Server editions. It is not available on Windows 10 Home or Pro.
  • Data Collected: Information restricted to the Malicious Software Removal Tool (MSRT), Microsoft Defender Antivirus status and definitions, and basic telemetry component infrastructure logs.
  • Data Excluded: No personal user data, application usage statistics, crash dumps, or hardware configuration metrics are collected.

Level 1: Basic

The Basic level is the baseline tier for standard consumer editions of Windows 10. It is designed to gather essential diagnostic details to identify hardware issues and compatibility problems.

  • Target Availability: Default minimum setting on Windows 10 Home and Pro editions; configurable across all editions.
  • Data Collected:
    • Basic device specifications (CPU architecture, memory size, storage capacity).
    • Operating system build versions, update installation status, and error codes.
    • Application compatibility details and driver inventory.
    • Quality metrics including system crash events and startup failure logs.
  • Data Excluded: User activity logs, software browsing behavior, and in-depth memory dumps.

Level 2: Enhanced

The Enhanced level expands on the Basic tier by gathering information on how the operating system and installed applications are used, helping Microsoft analyze broader user-experience patterns.

  • Target Availability: Enterprise, Education, and Pro editions (though streamlined into the "Optional" diagnostic category in later Windows 10 versions).
  • Data Collected:
    • System event traces and feature interaction logs.
    • Operating system and application usage duration and frequency.
    • Partial memory dumps generated when an application or the OS encounters a critical fault.
  • Data Excluded: Detailed user files, document contents, and deep-level crash dumps containing personal identifiers.

Level 3: Full

The Full telemetry level is the most comprehensive diagnostic setting available. It gathers all data provided by the Security, Basic, and Enhanced tiers, along with advanced debugging details to diagnose rare or complex system crashes.

  • Target Availability: Default configuration for Windows 10 Insider Preview builds; optional across all regular editions.
  • Data Collected:
    • Complete memory dumps, which may inadvertently capture user memory states at the moment of an operating system crash.
    • Diagnostic logs, system file snapshots, and detailed device health traces.
    • Registry settings and active network state information during catastrophic errors.
  • Privacy Protections: Microsoft implements automated scrubbing tools to identify and remove personally identifiable information (PII) before telemetry data reaches internal engineering teams.

Managing Telemetry Configuration

Administrators can enforce telemetry restrictions across managed devices using the Local Group Policy Editor or Mobile Device Management (MDM) profiles.

In Group Policy, navigate to: Computer Configuration > Administrative Templates > Windows Components > Data Collection and Preview Builds > Allow Telemetry

From this policy, administrators can explicitly set the desired level between 0 (Security) and 3 (Full). If configured on an edition that does not support the selected tier (such as selecting Level 0 on Windows 10 Pro), Windows automatically defaults to Level 1 (Basic).
