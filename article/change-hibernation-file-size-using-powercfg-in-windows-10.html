Change Hibernation File Size Using Powercfg in Windows 10

Windows 10 manages its hibernation data through a hidden system file named hiberfil.sys, which stores the contents of physical memory (RAM) when the system hibernates or utilizes Fast Startup. Administrators can adjust the size, type, and operational status of this file using the native powercfg command-line utility. By modifying these parameters, users can either conserve significant hard drive space or ensure the system has adequate capacity to safely write the full contents of active RAM to disk.

The Role of hiberfil.sys

When Windows 10 enters hibernation, it saves the current system state, open applications, and user session to hiberfil.sys located at the root of the system drive (typically C:\). By default, Windows allocates roughly 40% to 75% of total installed physical RAM to this file, depending on the active hardware configuration and whether Fast Startup or standard hibernation is enabled.

Accessing the Command Tool

All hibernation file configurations require elevated administrative privileges. To apply changes:

  1. Right-click the Start button or press Windows Key + X.
  2. Select Command Prompt (Admin) or Windows PowerShell (Admin).

Switching Between Hibernation Types

Windows 10 introduces two distinct hibernation modes that dictate the baseline size of the file: reduced and full.

  • Reduced Mode: Designed solely for the Windows 10 "Fast Startup" (hybrid boot) feature. It saves only the Windows operating system state and kernel session, ignoring open user applications. This significantly reduces file size to roughly 20% to 40% of installed RAM.

    powercfg /hibernate /type reduced

  • Full Mode: Supports standard hibernation along with Fast Startup. It retains the capacity to store the active user session alongside system drivers and kernel states.

    powercfg /hibernate /type full

    Note: A system must be set to full before standard hibernation features become accessible in the Power menu.

Adjusting File Size by Percentage

You can specify the exact size of hiberfil.sys by declaring a percentage of the total installed RAM. Windows imposes a strict minimum percentage—generally 40%—to guarantee sufficient room for essential kernel structures during shutdown.

To set the size, run the following syntax:

powercfg /hibernate /size <percentage>

For example, to set the hibernation file size to 60% of total system memory:

powercfg /hibernate /size 60

To maximize compression and configure the file to its minimum allowed size:

powercfg /hibernate /size 40

If an entered percentage is below the operating system's internal hardware safety limit, Windows automatically rounds the allocation up to the minimum allowable threshold.

Enabling and Disabling Hibernation

If disk space is critical and neither hibernation nor Fast Startup is required, the file can be removed entirely:

  • Disable and delete hiberfil.sys:

    powercfg /hibernate off

    (Alias: powercfg -h off)

  • Re-enable hibernation:

    powercfg /hibernate on

    (Alias: powercfg -h on)

Disabling hibernation immediately frees up drive space equivalent to the previous size of hiberfil.sys. Enabling it recreates the file on the root drive using the default configuration settings.
