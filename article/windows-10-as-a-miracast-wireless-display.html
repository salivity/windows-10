Windows 10 as a Miracast Wireless Display

Microsoft Windows 10 includes native support for Miracast projection reception, enabling a computer to act as an external wireless monitor for another Windows or Android device. This feature uses Wi-Fi Direct technology to create a secure, peer-to-peer screencasting link without requiring an active internet connection, external cables, or third-party software. Through the modular "Wireless Display" component and dedicated system settings, Windows 10 can receive mirrored or extended desktop sessions while optionally supporting backchannel inputs like mouse, keyboard, and touch.

Hardware and System Requirements

To function as a Miracast receiver, the Windows 10 host must meet specific hardware standards:

  • Network Interface: A Wi-Fi adapter that supports Wi-Fi Direct, Virtual Wi-Fi, and NDIS 6.30 or higher.
  • Graphics Display Driver: A graphics processing unit (GPU) and display driver compatible with Windows Display Driver Model (WDDM) 1.3 or higher.

To verify compatibility, open PowerShell or Command Prompt and run netsh wlan show drivers. Look for the line labeled Wireless Display Supported; it must indicate "Yes" to function as a receiver.

Installing the Wireless Display Feature

In recent versions of Windows 10, the receiver software is an on-demand optional feature rather than a default installation.

  1. Open Settings and navigate to Apps > Optional features.
  2. Select Add a feature.
  3. Type Wireless Display in the search bar.
  4. Check the box next to Wireless Display and click Install.

Once installed, Windows provides the "Connect" application (or "Wireless Display" app), which acts as the listening client for inbound Miracast signals.

Configuring Projection Settings

Once the feature is installed, you can configure how the operating system handles inbound projection requests:

  1. Open Settings and go to System > Projecting to this PC.
  2. Configure the following parameters:
    • Availability: Choose between "Available everywhere on secure networks" or "Available everywhere." Selecting "Always Off" disables reception.
    • Pairing Permissions: Set Windows to ask to project "First time only" or "Every time a connection is requested."
    • Security PIN: Require a one-time PIN pairing ("First time" or "Always") to prevent unauthorized connections in shared environments.
    • Power Management: Toggle whether projection is only permitted when the device is connected to a dedicated power source.

Establishing the Connection

  1. On the receiving Windows 10 device, launch the Wireless Display app from the Start menu. The screen will display the device name and notify you that it is ready for a connection.
  2. On the transmitting device (such as another Windows PC), press Windows Key + K to open the Cast menu.
  3. Select the name of the receiving Windows 10 PC from the list of available displays.
  4. On the transmitting device, choose the desired projection mode: Duplicate (mirroring), Extend (using the receiver as a second monitor), or Second screen only.
  5. If prompted, confirm the connection or enter the PIN shown on the receiver screen.

Input Redirection (UIBC)

Windows 10 supports the Miracast User Input Back Channel (UIBC). When projecting from a compatible source to a Windows 10 receiver, check the box labeled Allow mouse, keyboard, touch, and pen input from this device on the transmitting host. This allows the receiving machine's input peripherals to directly interact with and control the transmitting system in real time.
