Windows 10 High Contrast Mode for Accessibility

The Microsoft Windows 10 operating system includes robust high-contrast display modes designed to improve screen visibility and readability for users with low vision or light sensitivity. This article outlines how Windows 10 implements these accessibility features, the built-in themes available, how to activate them via system settings and keyboard shortcuts, and how to customize color palettes for optimal visual comfort.

How High-Contrast Mode Works in Windows 10

Windows 10 high-contrast mode functions by overriding the standard visual styles of the operating system. Instead of soft gradients, shadows, and subtle color distinctions, the system applies a distinct, high-contrast palette with sharply defined borders. This drastically reduces visual clutter, makes text edges sharper, and ensures interface elements—such as buttons, text fields, and icons—stand out clearly against backgrounds.

This functionality applies system-wide, affecting the desktop, File Explorer, the taskbar, system dialog boxes, built-in Universal Windows Platform (UWP) apps, and supported third-party applications and web browsers.

Built-In High-Contrast Themes

Windows 10 provides four pre-configured high-contrast color profiles:

  • High Contrast Black: Features a black background with white text, green hyperlinks, and purple accents. This theme is optimal for reducing screen glare and eye strain.
  • High Contrast White: Features a white background with black text, designed for users who require stark contrast without a dark interface.
  • High Contrast #1: A variation of the dark theme using yellow text on a black background to assist users with specific forms of visual impairment.
  • High Contrast #2: A variation of the dark theme using green text on a black background.

How to Enable High Contrast in Windows 10

Windows 10 provides two primary methods to turn on high-contrast mode:

1. Keyboard Shortcut

Press Left Alt + Left Shift + Print Screen. A confirmation dialog will appear asking if you want to turn on High Contrast. Selecting "Yes" immediately activates the feature. Pressing the same shortcut again toggles the mode off.

2. Windows Settings

  1. Open the Start Menu and click the Settings gear icon (or press Windows Key + I).
  2. Select Ease of Access.
  3. In the left navigation sidebar, select High contrast.
  4. Toggle the switch under Turn on high contrast to the On position.
  5. Select a theme from the Choose a theme dropdown menu.

Customizing High-Contrast Colors

Windows 10 allows users to build custom color schemes if the default high-contrast profiles do not meet their visual needs. Within the High contrast settings pane, users can select and modify individual color swatches for specific interface components:

  • Text: The primary color of standard reading text.
  • Hyperlinks: The color applied to clickable web links and navigation paths.
  • Disabled Text: The color for unavailable buttons or inactive options.
  • Selected Text: The highlight color used when dragging over text.
  • Button Text: The label text color inside clickable interface buttons.
  • Background: The base background color across windows and apps.

Once the desired colors are selected, clicking Apply prompts the user to save the configuration as a custom high-contrast theme for future use.

Web and Application Compatibility

When high-contrast mode is enabled, Windows 10 communicates this state to modern web browsers, including Microsoft Edge, Google Chrome, and Mozilla Firefox. Websites that support accessibility standards—such as the CSS forced-colors or prefers-contrast media queries—will automatically adapt their styles to match the user's selected high-contrast palette, ensuring a consistent and legible reading experience across both offline and online environments.
