How to Manage Fonts in Windows 10 Settings

Windows 10 streamlines typography management by transitioning font controls from the legacy Control Panel into the modern Settings app. This article explains how the operating system handles font management natively, covering how to view installed typefaces, preview styles, install new font files, download options from the Microsoft Store, and remove unwanted fonts.

Accessing the Fonts Menu

To manage fonts in Windows 10, open the Settings application by pressing Windows + I, select Personalization, and click on Fonts from the left-hand navigation pane. This page serves as the centralized hub for all typography installed on the system.

Installing New Fonts

Windows 10 provides two modern methods to install fonts through the Settings interface:

  1. Drag and Drop: At the top of the Fonts page is a dedicated drop target labeled "Add fonts." Users can drag font files (such as .ttf, .otf, or .ttc) directly from File Explorer and drop them into this area. Windows automatically unpacks and installs them.
  2. Microsoft Store Integration: A direct link titled "Get more fonts in Microsoft Store" allows users to browse curated, verified font packages. Installing a font from the Store requires only a single click on the "Get" or "Install" button, eliminating the need to handle raw font files manually.

Unlike older iterations of Windows that required administrative privileges to install fonts system-wide, modern Windows 10 installs fonts on a per-user basis by default. This enables non-administrator accounts to add their own custom fonts without modifying root system files.

Previewing Fonts and Adjusting Variables

The main section of the Fonts page displays a searchable grid of all installed font families. Selecting any font opens its dedicated detail view, which includes:

  • Interactive Previews: Users can type custom sample text into an input box to preview how it renders across different styles, weights, and point sizes.
  • Variable Font Support: If a font is an OpenType Variable font, Windows 10 provides dynamic sliders to adjust axes such as weight, width, and slant in real time, demonstrating the font's adaptive capabilities.

Viewing Metadata and Uninstalling

Below the preview tools, the Settings app displays detailed technical metadata for the selected typeface. This information includes:

  • Full font name and version number
  • Font vendor, designer, and copyright details
  • The exact file path where the font is stored on the drive (typically within the user's local AppData directory or the system C:\Windows\Fonts directory)

To remove a font, navigate to its detail page and click the Uninstall button. Windows automatically deregisters the font from running applications and removes the associated files from the storage drive.
