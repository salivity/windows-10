What is Windows Performance Recorder in Windows 10?

Windows Performance Recorder (WPR) is an advanced diagnostic logging tool built into Windows 10 that records detailed system performance events to help identify hardware and software bottlenecks. Based on Event Tracing for Windows (ETW), WPR allows system administrators, software developers, and IT professionals to monitor and capture in-depth data regarding CPU utilization, disk I/O, memory allocation, and system responsiveness. This article explains the primary purpose of WPR, how it functions, and how it is used to diagnose complex performance issues.

The Primary Purpose of Windows Performance Recorder

The main objective of Windows Performance Recorder is to capture comprehensive system event traces with minimal overhead on system performance. While Windows Task Manager and Resource Monitor show real-time metrics, they lack the historical granularity needed to pinpoint the root cause of transient glitches, high resource usage, or system latency. WPR fills this gap by collecting low-level OS and application events, creating an Event Trace Log (.etl) file that can be analyzed to resolve complex performance anomalies.

Key Capabilities and Features

WPR provides several specialized features designed for thorough performance troubleshooting:

  • Built-in Recording Profiles: WPR includes pre-configured profiles targeting specific performance areas, such as CPU usage, disk and file I/O activity, audio glitches, power management, and application startup times.
  • Custom Profiles: Users can create custom XML-based recording profiles to capture specific system and application-level events tailored to proprietary software or unique hardware environments.
  • Dual Operation Modes:
    • Memory Mode: Continuously logs events to a circular buffer in RAM, ensuring that normal system disk activity is not skewed by the recording process. This is ideal for capturing intermittent or hard-to-reproduce issues.
    • File Mode: Writes events directly to disk, making it suitable for tracking long-term operations, such as entire boot cycles or sustained stress tests.
  • Multiple Interfaces: WPR provides both a graphical user interface (wprui.exe) for straightforward, interactive recording and a command-line utility (wpr.exe) for automated scripts, remote management, and headless environments.

Integration with Windows Performance Analyzer

WPR is designed specifically to work in tandem with Windows Performance Analyzer (WPA), both of which are part of the Windows Assessment and Deployment Kit (Windows ADK). While WPR handles the data capture phase, it does not analyze the data itself. The recorded .etl trace file generated by WPR is opened in WPA, where the collected information is transformed into interactive graphs, call stacks, and data tables to facilitate deep root-cause analysis.

Common Use Cases

In Windows 10, WPR is primarily used to troubleshoot:

  • Slow Boot and Shutdown Times: Diagnosing delays caused by startup applications, driver initialization, or service timeouts.
  • System Freezes and DPC Latency: Identifying faulty device drivers that hold the CPU at elevated Interrupt Request Levels (IRQL), leading to audio dropouts or unresponsive user interfaces.
  • Memory Leaks: Tracking kernel-pool and user-mode memory allocations over time to find processes failing to release memory.
  • Application Hangs: Examining thread execution and lock contention to see why a program has stopped responding to user input.
