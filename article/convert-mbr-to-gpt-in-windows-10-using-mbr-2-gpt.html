Convert MBR to GPT in Windows 10 Using MBR2GPT

This article explains how the Microsoft Windows 10 operating system converts a disk from the Master Boot Record (MBR) partition style to the GUID Partition Table (GPT) format using the native MBR2GPT command-line tool. You will learn about the tool's underlying conversion mechanics, prerequisites, validation requirements, and the necessary firmware adjustments required to maintain system bootability without data loss.

Overview of MBR2GPT

Introduced in Windows 10 version 1703 (Creators Update), mbr2gpt.exe is a built-in utility located in the System32 directory. Traditionally, converting an MBR system disk to GPT required wiping the drive and reinstalling the operating system. The MBR2GPT tool automates a non-destructive conversion, allowing users to enable Unified Extensible Firmware Interface (UEFI) boot modes, utilize disks larger than 2TB, and take advantage of modern security features like Secure Boot.

Prerequisites and Validation Phase

Before making any changes to the partition layout, Windows performs strict validation to prevent system corruption. The conversion requires:

  • Disk Structure: The target disk must be an MBR disk. It can contain a maximum of three primary partitions to leave room for the required EFI System Partition (ESP). If extended or logical partitions exist, they must be removed or consolidated.
  • Boot Suitability: The disk must be an operating system disk containing a Windows 10 installation.
  • Free Space: There must be sufficient unallocated space at the beginning or end of the disk to create the ESP and GPT structures.
  • Firmware Support: The computer's motherboard must support UEFI firmware.

Administrators test readiness by executing:

mbr2gpt /validate /allowFullOS

The /allowFullOS switch is necessary when running the tool directly inside a live Windows 10 session. Without it, the tool expects to be run from the Windows Preinstallation Environment (Windows PE).

The Conversion Process

Once validated, the conversion is initiated using the following command:

mbr2gpt /convert /allowFullOS

When this command runs, Windows 10 executes the transition through a specific sequence of operations:

  1. Partition Table Construction: The tool reads the existing MBR layout and creates a corresponding GUID Partition Table structure at the start and end of the drive. The original data inside existing partitions remains untouched.
  2. EFI System Partition (ESP) Creation: Windows shrinks an existing partition (typically the OS partition) or uses adjacent unallocated space to generate a new FAT32-formatted EFI System Partition.
  3. Boot File Installation: The utility creates the necessary UEFI bootloader files inside the newly formed ESP, ensuring all required boot files (such as bootmgfw.efi) are present.
  4. Boot Configuration Data (BCD) Update: The BCD store is updated to point firmware startup paths to the new UEFI components instead of the legacy BIOS boot sectors.
  5. Finalization: The tool marks the disk conversion as complete and updates the primary partition table headers to GPT.

Post-Conversion Firmware Configuration

After MBR2GPT successfully completes the conversion, the operating system can no longer boot using Legacy BIOS mode. The final critical step requires restarting the computer, entering the motherboard's firmware settings, and switching the boot mode from Legacy BIOS (or CSM) to UEFI. Once configured, Windows 10 initializes via UEFI, completing the transition.
