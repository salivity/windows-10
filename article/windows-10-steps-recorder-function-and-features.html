Windows 10 Steps Recorder: Function and Features

The Steps Recorder utility in Windows 10 is a built-in diagnostic tool designed to help users capture and document issues they encounter on their computer. By automatically recording screen actions, keystrokes, and clicks, it creates an itemized, visual step-by-step report that can be easily shared with IT support specialists or help desk technicians. This guide explains the core functions of Steps Recorder, how it works, and how to use it for effective troubleshooting.

Primary Function of Steps Recorder

The fundamental purpose of Steps Recorder (historically known as the Problem Steps Recorder, or psr.exe) is to eliminate the guesswork involved in troubleshooting technical software problems. Instead of requiring a user to manually describe an error or capture multiple separate screenshots, Steps Recorder operates silently in the background, logging every action until the session is stopped.

Key Features and Capabilities

  • Automated Screen Capture: Every time you click the mouse or press certain keys, the utility takes a screenshot and marks the exact location of the click with a green border or highlight.
  • Text Descriptions: Alongside screenshots, the tool generates detailed text logs explaining the action, such as "User left click on 'File' in 'Notepad'" or "User scrolled mouse wheel up."
  • Custom Annotations: During recording, users can click the "Add Comment" button, highlight a specific area of the screen, and type custom notes to provide extra context.
  • Compressed Output: Once recording is finished, the tool compiles the images, text descriptions, and basic system technical details into a single MHTML (.mht) document and compresses it into a standard .zip file for easy email attachment.
  • Privacy Protections: To protect sensitive information, Steps Recorder automatically pauses text logging when entering passwords, though it does not record video or audio.

How to Use Steps Recorder

  1. Press the Windows Key, type Steps Recorder, and press Enter (or press Win + R, type psr, and hit Enter).
  2. Click Start Record.
  3. Perform the steps that trigger the error or issue you are experiencing.
  4. If needed, click Add Comment to highlight a specific element and add notes.
  5. Click Stop Record once you have demonstrated the problem.
  6. Review the generated steps in the preview window, click Save, and choose a file destination to export the .zip archive.

Limitations

Steps Recorder does not record video, nor does it capture fast-paced 3D graphics like full-screen video games. Additionally, Microsoft has designated Steps Recorder as a deprecated feature in recent Windows releases, encouraging users to transition to modern alternatives such as the Snipping Tool's screen recording feature or the Xbox Game Bar for dynamic video captures. However, for generating lightweight, static step-by-step documentation, Steps Recorder remains a functional and efficient utility in Windows 10.
