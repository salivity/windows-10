Prioritizing Wi-Fi Over Ethernet in Windows 10

This article explores the function of the Windows Connection Manager (WCM) service in Windows 10, specifically examining how it handles network interface selection and what role it plays when prioritizing Wi-Fi connections over wired Ethernet. While Windows natively prefers wired Ethernet due to its lower default routing metric, WCM serves as the central policy-driven engine that arbitrates active connections, manages route metrics, and enforces connection rules when administrators or users configure Wi-Fi to take precedence.

The Role of Windows Connection Manager (WcmSvc)

The Windows Connection Manager service (WcmSvc) is responsible for monitoring network interfaces, managing connectivity states, and preventing conflicting simultaneous connections. Under standard conditions, Windows 10 employs an automatic metric feature determined by the TCP/IP stack, which automatically assigns a lower cost (higher priority) to faster interfaces—invariably placing Ethernet ahead of Wi-Fi.

However, WCM acts as an abstraction layer above raw network drivers. It continuously evaluates connection availability, link state changes, and administrative policies to determine which network adapter should actively route internet and intranet traffic.

Managing Route Metrics and Adapter Precedence

When an administrator configures the system to prefer Wi-Fi over Ethernet—typically by manually assigning a lower interface metric to the Wi-Fi adapter or higher metric to the Ethernet adapter—WCM respects these routing table adjustments.

Once these parameters are defined:

  • Routing Decision Execution: WCM coordinates with the TCP/IP stack to route primary outbound traffic through the lower-metric Wi-Fi interface.
  • Dynamic State Evaluation: If the Wi-Fi connection fluctuates in signal strength or drops entirely, WCM immediately directs traffic back to the secondary Ethernet connection without requiring a full network reset.

Enforcing Group Policy and Connection Limits

WCM is the policy enforcement point for Windows Connection Manager Group Policies located under Computer Configuration > Administrative Templates > Network > Windows Connection Manager.

Key policy settings governed by WCM include:

  • Minimize the number of simultaneous connections: When enabled, WCM determines which network takes precedence and will actively disconnect or "soft-disconnect" less preferred connections. If Wi-Fi is configured as the primary interface, WCM suppresses background network activity on the Ethernet adapter to avoid split-routing.
  • Prohibit connection to non-domain networks: WCM evaluates whether the Wi-Fi or Ethernet adapter is attached to an enterprise domain and can suppress or prioritize connections accordingly, ensuring enterprise security policies are maintained during adapter switching.

Connection State Coordination ("Soft Disconnect")

When Wi-Fi is prioritized over Ethernet, WCM utilizes a mechanism known as a "soft disconnect." Rather than disabling the Ethernet hardware, WCM instructs the operating system to stop routing general internet traffic through the wired interface. This keeps the Ethernet link alive for low-level local protocols while ensuring that all primary browsing, corporate application, and operating system traffic routes exclusively over the designated Wi-Fi adapter.
