What is Windows Defender Application Guard in Windows 10?

Windows Defender Application Guard (WDAG) is a built-in security feature in Windows 10 designed to protect enterprise networks and individual systems from web-borne attacks and malicious files. By leveraging hardware-level virtualization, WDAG isolates untrusted websites and documents inside a lightweight, disposable virtual container, preventing malware, ransomware, and exploits from reaching the underlying host operating system.

How Windows Defender Application Guard Works

WDAG uses Microsoft's Hyper-V virtualization technology to create a hardware-isolated boundary between the user's desktop environment and potential threats. Instead of running directly on the host operating system, untrusted activities are executed within a separate virtual machine that has its own kernel, storage, and memory.

If a site or file contains malicious code, the payload remains trapped inside this isolated environment. Once the user closes the browsing session or container, the virtual machine is completely destroyed, wiping away any temporary files, malicious payloads, keyloggers, or injected scripts acquired during the session.

Primary Functions and Use Cases

  1. Secure Web Browsing (Microsoft Edge) WDAG primarily integrates with Microsoft Edge. In an enterprise environment, network administrators define a whitelist of trusted corporate websites and cloud resources. When an employee clicks a link leading outside this trusted boundary (such as an unknown public website or a suspicious link in an email), Microsoft Edge automatically opens that page within the isolated Application Guard container.

  2. Microsoft 365 Document Isolation In supported enterprise configurations, WDAG extends to Microsoft Office applications (Word, Excel, and PowerPoint). When a user downloads a document from the internet, an email attachment, or an untrusted network location, the file opens in an isolated container. Users can read, edit, and print the file without exposing the operating system to malicious macros or exploit kits.

  3. Protection Against Phishing and Credential Theft Because the isolated container does not have access to the user's host credentials, cookies, or enterprise authentication tokens, malicious sites cannot steal saved passwords or exploit local storage to gain access to corporate resources.

Operating Modes

WDAG functions in two distinct modes:

  • Enterprise-Managed Mode: Configured via Microsoft Intune, Microsoft Endpoint Configuration Manager, or Group Policy. Administrators define network boundaries, manage clipboard permissions, and dictate whether users can print or save files from the isolated container back to the host.
  • Standalone Mode: Designed for individual users running Windows 10 Pro or Enterprise. In this mode, the user manually launches an Application Guard window in Microsoft Edge to browse unfamiliar websites securely, independent of enterprise network policies.

System Requirements

To run Windows Defender Application Guard, a system requires a 64-bit processor with hardware virtualization (such as Intel VT-x or AMD-V) and Second Level Address Translation (SLAT), at least 8 GB of RAM, and a compatible edition of Windows 10 (Pro, Enterprise, or Education).
