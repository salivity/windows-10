Configure Static Routes in Windows 10 Using Route Add

Configuring a static route in Microsoft Windows 10 allows you to manually specify the network path network traffic must take to reach a specific destination network or host. This article explains how to use the built-in route add command within the Windows Command Prompt, the required syntax, how to make routes persistent across system reboots, and how to verify or remove configured routes.

Prerequisites

To add or modify routing tables in Windows 10, you must open the Command Prompt with elevated privileges:

  1. Press the Windows Key, type cmd.
  2. Right-click Command Prompt and select Run as administrator.

Basic Syntax of the route add Command

The core syntax for adding a static route in Windows 10 is:

route ADD <destination_network> MASK <subnet_mask> <gateway_ip> METRIC <metric_value> IF <interface_number>
  • <destination_network>: The IP address of the target network or host.
  • MASK <subnet_mask>: The subnet mask for the destination network (defaults to 255.255.255.255 if omitted).
  • <gateway_ip>: The IP address of the router/gateway through which traffic should be directed.
  • METRIC <metric_value> (Optional): An integer cost value used to determine route priority. Lower values have higher priority.
  • IF <interface_number> (Optional): Specifies the network interface index to use.

Adding a Temporary Static Route

By default, routes added via route add are temporary and will be cleared when Windows restarts or the network adapter resets.

To route traffic bound for the subnet 192.168.20.0/24 through a gateway at 192.168.1.1:

route ADD 192.168.20.0 MASK 255.255.255.0 192.168.1.1

If successful, the Command Prompt will display: OK!

Making Routes Persistent

To ensure a static route remains in the Windows routing table across system reboots, insert the -p flag immediately after the route command:

route -p ADD 192.168.20.0 MASK 255.255.255.0 192.168.1.1

Persistent routes are stored in the Windows Registry under: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\PersistentRoutes

Specifying an Interface Index

If your Windows 10 computer has multiple network adapters, traffic may need to exit through a specific network interface.

  1. View your network adapters and their interface IDs by running:

    route print

  2. The Interface List at the top displays the index number associated with each network card.

  3. Specify the interface index at the end of the command using the IF argument:

    route -p ADD 10.0.0.0 MASK 255.0.0.0 192.168.1.1 IF 12

Verifying and Removing Static Routes

To verify that the route was successfully added:

route print

Look for your entry under the IPv4 Route Table section, or under Persistent Routes if the -p switch was used.

To delete a configured static route, use the route delete command followed by the destination IP:

route delete 192.168.20.0
