How Windows 10 Handles Encrypted ZIP Folders

Windows 10 includes native support for viewing and extracting standard compressed files, but its ability to handle encrypted or password-protected ZIP folders in File Explorer is strictly limited. While the operating system can read basic archives encrypted with legacy methods, it cannot natively open modern AES-encrypted archives or create password-protected ZIP folders without third-party software.

Opening and Extracting Encrypted ZIPs

When you encounter a password-protected ZIP archive in Windows 10 File Explorer, native behavior depends entirely on the encryption algorithm used to secure the file:

  • Legacy ZipCrypto: If the archive was secured using the older, weaker ZipCrypto algorithm, File Explorer allows you to browse the contents of the folder. However, once you attempt to open, copy, or extract a file from within the archive, Windows displays a native password prompt requiring the passphrase before decrypting the data.
  • Modern AES Encryption (AES-128 / AES-256): Most modern compression utilities use AES encryption by default due to security standards. Windows 10 File Explorer does not natively support AES-encrypted ZIP folders. Attempting to open or extract an AES-protected archive typically results in an error message stating that the folder is invalid or corrupted, without presenting a password prompt.

Creating Encrypted ZIP Folders

Windows 10 cannot natively create encrypted or password-protected ZIP archives. The built-in compression utility—accessed via the right-click context menu by selecting Send to > Compressed (zipped) folder—only creates unencrypted, standard ZIP files. There are no settings, prompts, or options within File Explorer to apply encryption or set a password during creation.

Working Around Native Limitations

Because native File Explorer support is restricted to legacy encryption, handling secure archives on Windows 10 requires dedicated third-party archive utilities. Programs such as 7-Zip, WinRAR, or PeaZip must be installed to extract modern AES-256 encrypted ZIP files reliably and to create new password-protected archives.
