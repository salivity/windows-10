Configure Network Interrupt Moderation in Windows 10

Interrupt moderation in Windows 10 is a network card mechanism that bundles incoming packets and generates a single hardware interrupt rather than signaling the CPU for every individual packet. By managing interrupt moderation rates, the operating system balances processor utilization with network latency, allowing users and administrators to optimize for high-throughput environments or low-latency tasks such as online gaming and real-time audio streaming. Windows 10 configures these rates primarily through vendor-supplied network device drivers, Device Manager properties, PowerShell cmdlets, and the Windows Registry.

Understanding Interrupt Moderation Rates

When a network adapter receives packets, it issues interrupts to the CPU to process the data. Under high traffic, thousands of interrupts per second can cause "interrupt storms," overwhelming the processor. Interrupt moderation introduces a brief delay, coalescing multiple packets into a single processing cycle.

Network interface cards (NICs) generally support several moderation presets:

  • Off: Disables packet coalescing. The NIC fires an interrupt for every incoming packet, providing the absolute lowest latency at the cost of significantly higher CPU usage.
  • Low: Moderates interrupts lightly, suitable for environments requiring low latency while maintaining basic CPU safeguards.
  • Medium: A balanced profile providing standard network performance and modest CPU savings.
  • High: Heavily coalesces packets to minimize CPU utilization, ideal for high-throughput file transfers where latency is not a critical factor.
  • Adaptive (Dynamic): The default state for many modern controllers. The driver automatically adjusts the moderation rate based on current traffic volume and packet sizes.

Configuring via Device Manager

The most accessible method to modify interrupt moderation rates in Windows 10 is through the graphical interface provided by Device Manager:

  1. Press Win + X and select Device Manager.
  2. Expand the Network adapters section.
  3. Right-click the active physical network adapter and select Properties.
  4. Navigate to the Advanced tab.
  5. In the Property list, locate Interrupt Moderation and Interrupt Moderation Rate.
  6. Set Interrupt Moderation to Enabled or Disabled. If enabled, select Interrupt Moderation Rate and choose a value from the drop-down menu (Off, Low, Medium, High, or Adaptive).
  7. Click OK to apply the changes immediately. The network connection may momentarily drop and reconnect as the driver restarts.

Configuring via Windows PowerShell

Advanced configurations and automated deployments can be handled directly through PowerShell using the NetAdapter module:

  1. Open PowerShell with administrative privileges.

  2. View the current interrupt settings for an adapter:

    Get-NetAdapterAdvancedProperty -Name "Ethernet" -DisplayName "Interrupt Moderation*"

  3. Enable or disable interrupt moderation:

    Set-NetAdapterAdvancedProperty -Name "Ethernet" -DisplayName "Interrupt Moderation" -DisplayValue "Enabled"

  4. Set a specific rate (values must match driver-specific strings, such as Adaptive, Low, Medium, or High):

    Set-NetAdapterAdvancedProperty -Name "Ethernet" -DisplayName "Interrupt Moderation Rate" -DisplayValue "Adaptive"

Configuring via the Windows Registry

Windows 10 stores network driver parameters in the registry. Changes made here apply to the driver initialization level:

  1. Locate the adapter driver instance key under: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Class\{4d36e972-e325-11ce-bfc1-08002be10318}
  2. Identify the numeric subkey (e.g., 0001, 0002) corresponding to the specific physical adapter by checking the DriverDesc value.
  3. Modify the standardized driver keys:
    • *InterruptModeration: Set to 1 (Enabled) or 0 (Disabled).
    • ITR or *InterruptModerationRate: Controls the specific interrupt rate limit, frequently represented as an integer threshold defining the maximum interrupts per second (values vary depending on hardware vendors such as Intel or Realtek).

Performance Implications

Lowering or disabling the moderation rate reduces packet processing delay, decreasing round-trip network latency. However, doing so increases the interrupt processing workload on system cores. For modern multi-core processors running gigabit or multi-gigabit workloads, keeping the setting on Adaptive or Low provides the best balance between responsiveness and system stability.
