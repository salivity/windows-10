How Windows 10 UAC Manages User Access Rights

User Account Control (UAC) is a core security feature in Microsoft Windows 10 designed to prevent unauthorized changes to the operating system. By enforcing the principle of least privilege, UAC ensures that applications and users operate within standard user permissions by default, requiring explicit authorization whenever an action demands administrative privileges. This article explains the underlying mechanisms of UAC, including dual-token architecture, elevation prompts, the Secure Desktop, and virtualization.

Dual-Token Architecture

When an administrator logs into a Windows 10 computer, the operating system assigns them two distinct security access tokens through the Local Security Authority (LSA):

  1. Standard User Token: A filtered token with standard user rights used to launch the desktop shell (Explorer.exe) and run routine applications.
  2. Administrator Token: A full-privilege token that remains dormant until an administrative task explicitly requests it.

Standard user accounts, by contrast, receive only a standard user token. Because administrators browse the web, check email, and run everyday applications using the filtered standard token, malicious code introduced during daily activities cannot automatically gain root-level control of the device.

The Elevation Trigger and Prompt Types

When a process attempts to execute a task requiring administrative rights—such as installing software, modifying system-wide settings, or editing protected directories like C:\Windows—Windows 10 identifies the request through application manifests, heuristics, or API calls. UAC then halts the execution and issues an elevation prompt:

  • Consent Prompt: Presented to users logged in with an administrator account. The user simply confirms or denies permission to elevate the process using their dormant administrative token.
  • Credential Prompt: Presented to users logged in with a standard account. The user must provide valid credentials (username and password) of a local or domain administrator to proceed.

Once approved, the system generates the target process using the full administrative token, while the parent process typically remains restricted to the standard token.

The Secure Desktop

To defend against malicious software that attempts to spoof user input or forge approvals, UAC presents its prompts on the "Secure Desktop." When an elevation prompt appears, the current desktop fades to black and becomes inaccessible, isolating the prompt window.

The Secure Desktop runs in an isolated session that only system-level processes can access. This prevents user-mode keyloggers, screen scrapers, or click-jacking scripts from automatically clicking "Yes" or capturing entered credentials.

File and Registry Virtualization

To maintain compatibility with legacy applications designed to run with continuous administrative privileges, Windows 10 includes UAC virtualization. If an older application attempts to write to restricted system paths (such as C:\Program Files or the HKEY_LOCAL_MACHINE\Software registry hive) without administrative permissions, UAC intercepts the request and redirects the write operation to a safe, user-specific location:

  • File System: Redirected to C:\Users\<Username>\AppData\Local\VirtualStore
  • Registry: Redirected to HKEY_CURRENT_USER\Software\Classes\VirtualStore

This allows legacy applications to function normally without compromising system-wide integrity or granting the software unrestricted administrative access.

Configurable Protection Levels

Windows 10 allows administrators to adjust UAC sensitivity across four standard levels depending on security and usability needs:

  • Always Notify: Prompts for consent/credentials whenever programs make changes or the user alters Windows settings; utilizes the Secure Desktop.
  • Notify me only when apps try to make changes to my computer (Default): Prompts only when external programs request elevation, not during native Windows configuration changes; utilizes the Secure Desktop.
  • Notify me only when apps try to make changes (Do not dim my desktop): Same as the default setting, but displays the prompt on the standard desktop instead of the Secure Desktop.
  • Never Notify: Disables UAC elevation prompts entirely, elevating administrator accounts automatically and failing requests from standard users unless executed explicitly via administrator credentials.
